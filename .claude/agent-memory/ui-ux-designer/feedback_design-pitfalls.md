- **Entries.** A stub `libs/angular-ui-kit/<entry>/ng-package.json` with `entryFile: ../src/lib/<entry>/index.ts` is the pattern. A relative import across entries fails with TS6059. The Nx lint needs `allowCircularSelfDependency`.
- **esbuild.** A file that both the initial and a lazy graph reach goes into an eagerly loaded shared chunk. Lazy data therefore needs its own entry, with its own copy.
- **`@defer` dependencies** must be imported from the secondary entry and used only inside the block.
- **Hydration.** life-os runs `withNoIncrementalHydration()` because its CSP blocks the inline script, so `hydrate` triggers aren't available and the server renders `@placeholder`. A CSP fixture needs that setting plus `inlineCritical: false`.
- **DOM.** For DOM that must equal earlier output, use `DOCUMENT` APIs, not Renderer2 (it stamps `_ngcontent`). A server-side write belongs in an `effect`, not an `afterRender` hook.
- **CSS specificity.** `a.btn` (0,1,1) beats `.btn-inline`; use `.btn.btn-inline`.
- **Spec premises.** Measure a requester's size figures before accepting a target. In 002, "136 SVGs ≈ 20 kB" turned out to be 12.0 kB; in 007, "≈ 9 kB" was 2.5 kB, and only 0.33 kB of it was removable. A dependency the app already ships (Router, rxjs) saves nothing. Check whether a removal would break an existing spec assertion (AC "tests unchanged"). Measure wrap row counts too: URL runs break only at hyphens, so the estimate of 3 rows was really 4 (004).
- **Token values.** Read the value before writing "token (N px)". `--border-radius-sm` is 10 px, and there is no 4 px radius token.
- **"Output equal to the old version."** Capture the old output in the browser before promising it. The innerHTML-era code block had quirks that came from HTML-parser recovery: SCSS showed `&amp;`, multi-line tokens were coloured on the first line only, and an empty line collapsed to 0 px (003).
- **Global element styles.** `_typography.scss` gives every `pre` `overflow-x: auto`, so inside lc-code-block the `pre` was the real scroller (axe flagged `.code-block__pre`, not the body). Measure which element scrolls before placing `tabindex`. A ring inside `overflow: hidden` must be inset.
- **Wording.** Check an AC's wording (for example "no emitted .js contains X", "file unchanged") against what the design has to move.

- **Gradient bands.** On a 135° band the top-right corner is at t = w / (w + h), which is 0.88 for 1280 × 168, so "top-right on a card" fails a t ≤ 0.75 rule on any compact band. A taller text doesn't help, because the media column centres vertically. Prototype the placement with `--measure` before you fix it in a design, and name the measuring point (the box centre).

- **CSS limits (006).** CSS can't read a sibling's height: to "grow the land by the footer", give the footer its own grid row painted in the gradient's end colour. An inline `height` can't be overridden from a stylesheet, but `min-height`/`max-height: var(--hook, 0px / none)` clamp it and leave the DOM unchanged. Injected `.btn` markup is unstyled in a story that renders no button (the stylesheet registers on first render).
- **Edge features need both edges (006 r1).** A "flush with the edge" design must cover the end edge too: grep the consumer's markup for the row (`justify="between"`) before fixing an alignment at high specificity; expose it as a hook (`--lc-btn-flush-align`). Copy the consumer's `align-items` into the story row too: the default `stretch` made a one-line link's box and focus ring 69 px instead of 46.5 (r2 nit).

- **Prerender serialisers (008).** Domino (platform-server 21/22) writes `textarea.value` as text and escapes `& < >`, but omits the spec's extra LF after `<textarea>`/`<pre>`: a leading newline is lost. Angular 21's default build re-serialises through beasties (`decodeEntities: false`): bare empty attributes (`placeholder`, `required`), no `jsaction`. Compat regexes must accept both forms.
- **output() → model() is a member removal (008 r1).** Replacing `xChange = output()` with a model drops the public class member `xChange`; the 2.0 changelog calls that a break. In a minor, keep `readonly xChange: OutputRef<T> = this.x` (no duplicate output, no MCP duplicate) and give the type narrowing a line under Compatibility.

- **Flex wrap and 200 % text (009).** A flex basis of 0 never wraps (the AS-30 `brand flex: 1 1 0` overlap); a basis of the full content wraps at 100 % with a long subtitle. Use `width: min-content` plus `contain: inline-size` on the shrinkable text. `overflow-wrap: break-word` doesn't lower min-content; `anywhere` does. A sticky grid item is held inside its grid area, so a bar can't both stick and reserve its own row: clearance from a bar's real height needs a ResizeObserver. **Wrapping labels in nav columns (009 r1):** specify the vertical alignment and a minimum gutter. Centred columns made the icons zigzag by up to 48 px, and a reach of 0 put two German labels 1.2 px apart, so they read as one compound. Use `flex-start` with the old centring offset as padding. Chromium hyphenates capitalised German labels but not capitalised English ones (`lang="en"`), so EN nav labels at 200 % break without hyphens. Expect it; don't file it as a kit bug.

- **`anywhere` is not free (010).** It lowers min-content to one character, so in a *non-wrapping* row a one-word button shrinks with its neighbours at 100 % ("Bearbeiten" 116.7 → 93.8 px, 2 lines). Apply it to boxes that already have `min-width: 0` (titles) or through a hook in wrapping rows, columns and block flow, never globally on `.btn`. Content-dependent "icon above the title" = flex-wrap with the title `flex: 1 1 0%; max-width: 100%` and `break-word` (its auto-minimum is the longest word); a grid can't wrap.

- **CSP `style-src` without `'unsafe-inline'` (011).** On the server (domino), `[style.x]` bindings and CSSOM writes are both serialised as `style=""`. In the browser, CSSOM is allowed and parsed or `setAttribute` styles are blocked. Moving an inline style into a class drops its precedence from "beats everything" to the class's specificity, so restate the property (`svg { color: inherit }`) to keep global rules out. `min()` alone doesn't stop text overflowing a column; add `anywhere` in boxes whose tracks have a definite minimum. Component styles are appended to `head` after the app's stylesheet, so a global rule needs *more* specificity than the component rule to win: an equal one loses the tie (011 r1).

- **Template binding order (012).** Angular applies every property binding before any attribute binding (`UPDATE_ORDERING` in @angular/compiler), so `[src]` lands before `[attr.loading]`. For lazy images, bind `[attr.loading]` and then `[attr.src]`. `[width]="undefined"` writes `width="0"`, so use `[attr.width]` (null means absent). The `loading` name collides with the kit's boolean busy flag (button, select); a `'eager' | 'lazy'` union keeps them apart. **Story assets (012 r1):** the Storybook preview defaults to dark (canvas rgb(10,18,27)), so a custom-src story needs a dark partner: the mono emblem (#111827) was 1.06:1 and cost a round. In timing protocols, toggle every element first, then read: toggle-and-read in turn measures a half-toggled wrapping row.

- **axe 4.14 label in name (014).** `label-content-name-mismatch` is in `wcag21a` and matches whole words (NFKD, **parentheticals dropped**, non-letters → space): `Label, JM` passes, `Label (JM)` fails; one-character visible text ("J", "?") is always `incomplete`. It counts `aria-hidden` text as visible. An `lc-icon` without `decorative`/`ariaLabel` renders an unnamed `svg role="img"` (`svg-img-alt`): inside named controls use `[decorative]`. Before promising "no violations", run the full tag set on the stories: 014 found `svg-img-alt` and 8 other components the spec didn't know about.
- **Concatenated visible text (015).** axe joins adjacent element texts with `''`, and Angular strips whitespace-only text nodes, so "Tenant" + "Acme Corp" becomes `TenantAcme Corp`, and a step becomes `2ProfileSet up…`. Put `&ngsp;` between the parts; inside flex or block parents it renders nothing (372/372 shots hash-identical). The accessible name adds spaces around custom elements (lc-badge) but not around spans, so consumer templates need the spaces too. A number glyph next to a label can't be contained, so make it `content: attr(data-x)`. A `title` that differs from the name becomes the description, which stutters. A new name composition (label + template text through `aria-labelledby`) makes labels that consumers set under the old advice repeat the text ("Item one, Item One…"), so plan a Compatibility line for it in the design (015 r1 should-fix).

- **Ids (016).** An input named `id` on a component also leaves a static `id="x"` on the host, so the id appears twice (lc-checkbox, lc-radio). The MCP extractor ignores `alias:`. A per-app counter (a root service) repeats `x-0` across the stories of a Storybook Docs page, because each story is its own app, so use a module counter plus an explicit id input. A public field that becomes a getter keeps reading intact. `a[lcButton]` (ButtonLinkComponent) is the kit's anchor-as-button; specs tend to miss it. **Story compositions need the 44 px rule too (016 r1):** `[inline]` summary links were 17 px high, 4 px apart, and cost a round; use `[flush]` for links that stand alone (016 r2: a list of them leaves about 30 px under the last 14 px link; a `<ul>` with `list-style: none` needs `role="list"` for Safari/VoiceOver). Before naming a button size in a narrow story, check its min-content at 200 % (`lg`: 96 px padding + the longest word).

- **Contrast in `lc-hero`'s body (017).** `.hero__body` has `opacity: .85`, so anything projected into the default slot is composited at 85 % over the band. Measure it that way, at the worst t over the whole band, with the ring included. The kit ring (`--color-primary-500`) is invisible on the teal band. Theme-independent surfaces such as hero bands need theme-independent variants (SCSS palette values), not semantic tokens that flip in dark. A class shared by a state and a message (`.input-error`) leaks layout rules: grep each class for all its uses before naming. **Expected-diff lists (017 r1):** find every story that shows the changed state at load, including wrappers (lc-email-input's required message in *Invite Form*), by measuring the state class across the baseline stories, not by reading story names; add up the story counts.

- **Container queries and word breaking (018).** A query measures the content box, so a 1 px border moves `16rem` to 258 px (border-box). `hyphens: auto` lowers min-content to syllables ("Nicht eingetragen" 153 → 68 px), so a title hyphenates beside the icon instead of the AS-32 wrap. On a `lang="en"` canvas it changes wrapped lines in existing stories. `break-word` turns a 1 px overflow into a one-letter orphan ("fehlgeschlage|n"). Scope both to the narrow layout. `container-type` also brings layout containment (fixed descendants, no baseline). **It also changes the raster of text elsewhere on the page (018 r1).** Density side-by-side 1280 showed breadcrumb anti-aliasing diffs 850 px above the alerts, with 0 of 249 boxes moved. To prove the cause, inject `container-type: normal`; that restored the baseline hash. Don't write it off as font noise. **Check "the column is wide enough" claims against a 30-character compound** ("Benachrichtigungseinstellungen" is 218 px at 100 %) and against the controls beside the text (×, inline button) at 320 px / 100 %.

- **Theme hooks and projected content (019).**
  - Custom properties declared on an *inner* element (`.lc-sidenav--dark { --lc-sidenav-bg: … }`) override what an app sets on the host. A theme input therefore has to set private host variables that the public hooks read first.
  - `--color-primary-100…900` flip in dark. For a theme-stable look use `--color-primary-fill(-hover/-active)` and `--color-on-primary`.
  - Projected `[slot]` children don't carry the wrapper's `_ngcontent`, so `.wrapper > *` never matches them. Fill them through grid stretch on the wrapper instead.
  - A `theme=` rail re-themes only what reads the sidenav hooks. Focus rings (`--color-primary-500`), the active bar and child components (lc-badge) follow the *page*, and themes are `:root`-only. So list the "light rail on a dark page" pair in §5 (019 r1 must-fix: ring 1.89).
  - Moving the brand into a full-height rail (019 r2): spell out the header's title (page, not product) and its phone state in §8, or the story shows the name twice from 1024 px and none below. `.lc-sidenav__logo` keeps a 1 px border-bottom on the transparent variant, so it stops at the rail edge under a borderless header.
  - In `--measure` CSS, write `~` for `;` and call `.replaceAll("~", String.fromCharCode(59))`, so the Bash checker passes.

- **Ancestor-set hooks (020).** Any kit declaration of a public hook on `:host` masks values set on an ancestor, whatever its specificity. To honour both element and ancestor, declare no public hook on the host, put defaults in private vars, and read `var(--lc-x, var(--_x))` at every site (and guard it with a regex spec). Requester px targets can contradict the kit header (16 / 24 px): measure the element they must align with before accepting the numbers.
  - 020 r1: a wrap rule given to one text element (the md message) has to go on every text that grows (the md heading, 20 px, overflowed at 320). In wireframes, add the container's own `gap` (lc-app-page 24/40) to vertical distances. `--color-error` is a fill, the same in both themes; text needs `--color-text-error` (lc-menu danger was 2.06:1 in dark).

- **Latent bugs found while designing (022).** lc-switch `labelPosition="right"` renders the label *left* (row-reverse), so both values look alike: don't design against the input name. lc-table's tree-row focus ring sits only under `--striped`. Money: never trust `Intl` fraction digits for currencies (use an ISO 4217 table) and never divide minor units as floats. Use the element sweep (count labelled vs unlabelled instances per story) to build expected-diff lists.
  - 022 r1: emulated encapsulation adds `[_ngcontent]` to every compound, so `.lc-table thead tr th { text-align: left }` weighs (0,5,3): story `::ng-deep` classes and even the kit's `.lc-table th.lc-table__actions-cell--end` (0,4,1) lose, and `actionsAlign="end"` headers stay left. Measure header alignment (Range right vs cell right); never accept "the header aligns" from a selector.

- **Busy states and motion (021).** `opacity` on a button also fades its focus outline (the teal ring at 0.5 is 1.96:1), so a dimmed but focusable state needs a darker ring colour or `opacity: 1` on focus. The global reduced-motion `*` rule only shortens animations (0.01 ms, 1 iteration), so an indeterminate bar stops as a 40 % segment, which reads as a value; give it its own static look. story-shots always emulates reduced motion; `--forced-colors` (since 021) matches the media query, but headless light forces no real palette. **021 r1:** a `cellClass` colour or font size never reaches an lc-table `td` (the kit rule is (0,5,3)), so colour cells with `cellStyle` and never design with `cellClass` for colour (I did, and the build needed `!important`). Request 024 (3.19) designs the fix; check the released version before you rely on it. A Range over a `td` that holds `lc-money` reads about 113 px too far right because of its sr-only text: measure the `[aria-hidden]` span. If a stories file is newer than the developer's shots, re-compare that component on the current build. In an absolute sort indicator, the DOM order sets the header's accessible name ("ARR ↑" vs "↑ ARR"): move it with CSS, not in the DOM. The sweep: `$(…)` substitution and `for` loops are blocked in Bash, so pass the story IDs literally.

- **Story args and limit semantics (023).** A story template that binds `[variant]="variant"` without the arg passes `undefined` and renders `lc-x--undefined` (bottom-nav Default looked undocked for releases); check the class with `--measure` before you use a story as a reference. When a spec "only appends" an entry (showMore), check the documented meaning of the limit input (`maxItems` = most entries) at `count === limit` and `limit + 1`: appending gave 6 then 5 entries. **023 r1:** the developer's changelog hint told the requester to drop its own `activeRoute` mapping, but its "More" pages (`/datenbasis/…`) aren't under `moreRoute`. Grep the requester's routes and shell before you approve a migration hint, and give the corrected sentence word for word.

- **Specificity fixes and story CSS (024).** Angular's emulated shim scopes *inside* `:where(…)`, so `:where(.lc-table tbody tr td)` weighs 0 and any consumer class wins (prototyped). Lowering a rule wakes declarations it used to beat: `.lc-table__empty { color: secondary }` had never applied, so list every rule that lost before. A plain `<style>` in a story template is scoped to the story component and never reaches kit internals; stories use `::ng-deep` for global CSS. Grep a component's existing public hooks before proposing an input (`--lc-select-clear-display` already hid the ×). Never design `overflow-wrap: break-word` alone for German text: pair it with `hyphens: auto` (lc-alert pattern), or "Benachrichtigung|seinstellungen" splits without a hyphen (024 r1). Under `ViewEncapsulation.None` a `:host` rule is dead (lc-toast host is `inline` in a block parent), so put story `lang`/wrappers on the host, not a block wrapper.

- **Dead rules have dependants; hyphens on EN (025).** lc-toast-outlet relied on the dead `:host` rule staying dead (content-sized toasts, gap 0), so revive such a rule only for the other context (`lc-toast:not(lc-toast-outlet lc-toast)`), and prove it with click-opened `--compare` shots. Plain `hyphens: auto` on the `lang="en"` canvas hyphenates short EN words ("min-utes", "con-nection"); `hyphenate-limit-chars: 12 4 3` keeps every EN line and still breaks DE at syllables (Safari ignores it). Changing a story wrapper from flex to block changed the dark-gradient raster with equal boxes: keep the wrapper's display when the goal is "identical". Injected prototype CSS needs a ×3 repeated class to beat `[_ngcontent]` rules (width stayed 32 while the margin applied).

- **"Lowest" and range claims (026).** Before you quote a minimum, measure every variant in both themes. 025 measured dark only for All and Error and called 1.89 the lowest; Warning in dark was 1.44, and the error went into a comment and the changelog. To prove "only the colour changed", re-shoot with the old value injected (`color: buttontext`) and use `--compare`. A new kit colour on a formerly unstyled element silently beats consumers' equal-specificity global patches (kit sheets load later): the changelog must name a stronger selector, not "or loaded later" (026 r1).
- **Intl stripping and story DOM (027).** To drop a currency, filter `formatToParts` (remove the `currency` part and whitespace in the adjacent `literal`s only). Never strip whitespace globally: fr-FR groups with U+202F. Never switch to `style:'decimal'`, whose grouping differs in 1,012 of 153,216 cases (de-AT `11 111,11`). The isolated story DOM holds a Storybook docs args `<table>` first, so query `lc-table table`, not `table`. A spec's failing-cell list taken from an older probe can miss cells (toast warning L 2.16): recompute the full grid. **027 r1:** an lc-table `formatter` returns a plain string with no spoken text, so a "drop your hidden sr-only word" migration hint holds only for `lc-money` in a cell template: give that caveat in the story text and the changelog.

- **Chart text (028).** SVG `<text>` can't wrap, and its rem font grows at 200 % while the px bands (`PADDING_LEFT 40`) don't. Labels that must fit are HTML; bar lengths go into SVG *attributes* as `%` (`<rect width="57.5%">` in `<svg width="100%">`), which needs no DOM and is CSP-safe. All 13 kit charts build an English "X chart: …" aria name, replaceable only through the full `ariaLabel`. **028 r1:** a zero line *inside* a bar track is invisible, because every bar starts or ends at zero and covers it (and `--color-border` is too faint anyway): extend reference lines past the bar (`y1="-25%" y2="125%"` on an `overflow: visible` track) in a ≥ 3:1 ink, and look at a 4× zoom shot before specifying any 1 px mark. Vertical label cells at 200 % in a 294 px card are 56 px: words break inside ("Dem|o"). **r2:** an overhang in % of a hookable size grows past a fixed px gap (25 % of a 1.5rem bar = 6 px into a 4 px gap). Check the largest plausible hook value against glyph ink, not only the default.

- **Ink swaps (029).** The ink pairs are tuned for the `--color-<v>-subtle` tokens, not for components' raw `.18` tints (darker in light): check text on the real tint over every base (elevated card top = surface-2, selected, unread rows) before promising 4.5. An opacity-dimmed off state can't be fixed by a hue swap, and the ink can be *darker* than `-default` in dark (warning `#f1d3a7` → `#e1a040`): recompute dimmed and dark cells too. Spec "success/info" names may not exist in a component (pipeline: complete/current). **029 r1 must-fix (my design):** "the terminal rules stay" was false: `.x__level { .terminal & { .line--warn & {} } }` compiles to `.line--warn .terminal .x__level`, a dead rule, so the always-dark terminal took the theme ink (light 1.13–2.40). Before writing "X stays" for a variant, measure that variant's computed colour after the swap; theme inks never suit a theme-independent surface. **029 r2:** a colour ratio in §5 or the changelog says nothing about the rendered text when an ancestor has `opacity` (log debug line 0.6: 5.81 colour → 2.97 real); measure colour × the product of all ancestor opacities and quote the effective value, or name the dim as Known.

- **Sketch existing layout from measurements (031).** My §3 wireframe put the stat-trend icon at the card's right edge. It actually follows the label (the tile is `inline-flex`), and the review had to correct the design. Before drawing an unchanged component inside a new story, measure the icon x and the row heights with and without optional parts.
- **Story text and fixed dates (030).** Don't ask for `${CONST.length}` in a story description: the MCP manifest reads descriptions statically, so a literal count ("All 150 constants") is right and must be bumped by the next request that appends glyphs. For "stable" timestamps, specify local-time `new Date(y, m, d, h, …)`: `Date.UTC` renders in the machine's zone (08:00 UTC showed 09:00 in CET shots). Making a glyph inline changes `unregistered: 'placeholder'` apps that drew it themselves (fetched before → placeholder now): put that in Compatibility.
- **"Spec file passes unchanged" (032).** Before writing that in §9, grep every spec in the folder for the property the fix moves (`style.width`): `skeleton.height.spec.ts` asserted the fill width too, contradicting AC-2, and became a build deviation. **048:** grep all of `src/lib`, not the folder: the cross-component `lib/i18n-labels.spec.ts` pinned the datepicker's `toDateString()` name.
- **Overlay language (048 r1).** CDK overlay panels sit under `<body>`, outside a `lang="de"` story wrapper: a `locale="de-DE"` panel resolves to `<html lang="en">` (3.1.2). Check `panel.closest("[lang]")` in DE reviews of overlay components. **049:** story-shots measures can't read the story id from `location.search` (detect the component by DOM); a "closest `[lang]`" rule always finds `<html lang>` in real pages, so a `locale` fallback only acts in jsdom tests; a day panel showing the current month moves its today marker daily: navigate to a fixed month before hashing.
- **Requester widths vs the 328 canvas (033).** A spec's "328 px container" may not reproduce the requester's wrap (BA-8 fit at 328 even with the bug). Rebuild the requester's real container (app-page 312 − card border/padding) in the story, and pick a measure that discriminates at any width (value − leader gap 8 vs 48), not only line counts.
- **"Identical" baseline from another component's story (033 r1).** `components-card--footer-slot` was in the baseline as proof a card's list stays put, but card.stories doesn't import `DescriptionListComponent`: the list never renders (measure 0 rows, box 294×0). Before citing a cross-component story as evidence, check the measure's element count is > 0.

- **DE review stories (034 r1).** When §7 sets German labels for a story, list every visible built-in string of the component (NC: clear-all, search placeholder, filter chips too), or the shot mixes languages; and put the rows the AC needs above the fold at 360.
- **Two-layer fills and color-mix reads (034).** An opaque base plus a same-colour one-colour gradient on a rounded chip changes the corner raster, so the light shots differ even though the colours are equal. Prove that with a negative control (inject one layer: identical; two layers: different) and list those shots as raster-only diffs. `getComputedStyle().color` of a `color-mix()` returns `color(srgb r g b / a)` in 0–1 floats: scale by 255 before the WCAG formula (my first match values were wrong). Check every spec premise that something "stays ≥ X" (card chip border "stays ≥ 3" was 1.37). A `::before` hit area is limited by an ancestor's `overflow: hidden` and by later positioned siblings: hit-test it with `elementFromPoint` before quoting a size.

- **Flush forms (035).** Paint hover and ring on a `::before` bleed box (`inset-inline: -8px`, `z-index: -1` in an `isolation: isolate` header) so padding stays 0 and the ring stays inside the header vertically; `overflow-x: visible; overflow-y: clip` keeps a 0fr collapse while body rings reach past the edge. In emulated forced colours an author outline is forced to CanvasText: set `Highlight` explicitly. The global reduced-motion rule leaves transition *delays* (accordion body 50–300 ms): use `transition: none`. Injected plain rules lost to accordion size rules of equal weight (sm/lg body padding): order and weight matter. **035 r1:** a length hook used in `calc(-1 * var(--x))` breaks on a unitless `0` (number, invalid at computed time → `::before` 0 px wide, ring gone); write "a length, `0px` not `0`" in every consumer doc of such a hook. **038 fix pattern:** register a *private* `--_lc-x` (`@property`, `<length-percentage>`, `inherits: false`, `initial-value: 0px`), declare it on the element from the public hook, read only it in `calc`: bare `0` works, token default and public hook type stay, all valid values identical (11 measured); Angular's shim passes `@property` through unscoped, critical CSS keeps inline styles (`reduceInlineStyles: false`); Firefox < 128 falls back to the old calc, so keep "`0px`" in docs. A bleed past the content edge adds that much horizontal scroll in a scroll container without inline padding (measured 8 px). **038 r1:** a changelog that "resolves" earlier *Known* items must say which one is fixed and which is only documented. Plain bleed at 1024 = 1280 (header max 560, card 430).

- **036.** Earlier request blocks in `theme-contrast.spec.ts` pin their own "out of scope / follow-up" values (034: `depends` neutral-400, ring secondary token, `graphic` minimum; 029: bar secondary "stays raw"): grep for the follow-up's values before accepting an AC "no edited assertion", and list each one with its reason. `.storybook/preview.ts` imports Button, ButtonLink, Avatar, Chip … globally, so a story only misses the others (DescriptionList). After a `className` swap in `--measure`, wait ~150 ms: the reduced-motion 0.01 ms transition returns the old padding/font-size too. **036 r1:** making a story German is a layout change. Measure every row of controls in it (header, toolbar) for `scrollWidth − clientWidth` at 320 and 360 before writing "that stays": the NC header clipped "Alle löschen" by 13 px. A wrap fix with `row-gap` only (no column gap) keeps headers that fit today hash-identical. The developer's focus measure blurs at the end, so its shots show no ring: shoot focus separately.

- **037.** Never name a component input `routerLink`: a consumer that imports `RouterLink` gets the directive on the host too (second navigation, stray `tabindex="0"`); use `route` + `queryParams`, with `RouterLink` only inside the `@if` branch so no `Router` is injected otherwise. Stretched link (title `<a>` + `::after inset 0`) beats an `<a>` around the card (name = all text, nested controls, parser splits nested `<a>` in SSR); ring via `:has(.x:focus-visible)` on the card, `isolation: isolate` keeps the overlay's z-index local. `min-width: 0` + `break-word` on a flex title breaks short squeezed words mid-word (*Section Cards* "Proj|ects"); `hyphens: auto` + `hyphenate-limit-chars: 12 4 3` alone wraps long DE compounds (needs `lang="de"`) with zero existing diffs.
