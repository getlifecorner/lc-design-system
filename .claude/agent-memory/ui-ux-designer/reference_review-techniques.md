- **Bash prompts on** `node script` (incl. `tools/compat/check-trusted-types.mjs`: leave it to the release-manager), `python3`, `gzip`, `shasum`, `md5`, `sed`, `$(…)`, `for` loops with `${…}`, and on `;` inside `--measure`. To hash-compare shots, re-shoot with `--compare` (84 `--full` shots take a few minutes). Compute in the browser through `story-shots --measure` instead: WCAG formula on computed colours, gzip with `CompressionStream('gzip')`, chunk strings with `fetch()`. Write measures with commas and expression-bodied arrows. To wait, use `(await new Promise(r => setTimeout(r, 700)), …)`. An arrow that uses `await` must itself be `async`. Inside a container query, read styles only after 2 rAFs: a synchronous read after setting a custom property returned a stale `min-height`.
- **Multi-step measures:** `(async (b, f) => ({ rest: …, x: (b.focus(), await rafx2, …), axe: … }))(el, helper)`; properties evaluate in order, and the shot is taken after the measure, so a focus shows. Forced colours: `story-shots --forced-colors` emulates them (since 021; Highlight reads rgba(5,0,73,.8) L / rgba(0,230,255,.8) D, gradients compute to `none`). A trailing `ENOTEMPTY` rmSync error from story-shots is cleanup noise; the shots are complete.
- **Quoting in `--measure`.** The Bash checker decodes `\uXXXX` and rejects `$`, backticks and `2>&1` next to a redirect. Build those characters with `String.fromCharCode(39/36/96/59/35/38)`, and run `cd <repo>; node tools/agents/story-shots.mjs … | grep -o '"measure":.*'` without any redirect. `updateStoryArgs` applies only args the story declares: `copyLabel` didn't apply.
- **axe:** since 014 `story-shots --axe[=<tags>]` runs the axe-core devDependency (4.14.0) after `--measure` (so a measure can open a menu); the log line gets `"axe":{version,violations,incomplete}`. For another version, inject `https://cdn.jsdelivr.net/npm/axe-core@<v>/axe.min.js` in `--measure` (script element, `onload` resolves), then `axe.run(document)`. Isolated stories always report `landmark-one-main`, `page-has-heading-one` and `region`. Prototype a CSS change with inline styles in `--measure` before designing it. `outlineColor` read from an inline `outline` shorthand that uses `var()` came back as currentColor; trust the shot or the stylesheet rule.
- **Reading logs.** `grep -o '"width":[0-9]*,"theme":"[a-z]*"\|"measure":.*' x.log | paste - -` works. To compare shot files across runs, use `cmp a b` (allowed).
- **The 66-story baseline compare takes about 25 min**, and 192 `--full` shots (32 stories) took 5–12 min (009). Several story-shots runs can work in parallel (random port, temp profile). A `for s in …; do … $s` loop is refused ("variable can't be checked"), so write one command per story. Ink gaps between labels: `document.createRange().selectNodeContents(l).getClientRects()` per line. Run them in the background and poll with `grep -c '"file"' <log>`. A node wait-loop prompts.
- **Story id in `--measure`:** the page URL is the server root (no `?id=`), so pass the id as a literal. For an undeclared arg, rebuild the element in the DOM and copy the `_ngcontent-*` attributes so the scoped styles apply. `window.ng` exists in the static build. Wrap the measure in `.catch(e => ({ err: String(e) }))`, because a throw prints no measure at all. Put the `.catch` on the outer IIFE call: `(await p, obj).catch` throws, and the shot line then has no `measure` key. `diff -rq <baseline> <dir>` compares a whole shot folder in one command, so a developer's compare folder can be re-checked without re-shooting (011). Stories shot `--full` in the baseline differ by hash when re-shot without it; compare them with a `--full` run.
- **Args and play steps.** To toggle args: `__STORYBOOK_ADDONS_CHANNEL__.emit('updateStoryArgs', { storyId, updatedArgs })`, then wait about 600 ms. Copy buttons: `Object.defineProperty(navigator.clipboard, "writeText", { value: t => Promise.resolve(), configurable: true })`, then `.click()`. story-shots doesn't wait for `play`, so poll for its end state.
- **Unstable baseline shots (002):**
  - `components-chat--message-status` and `--user-avatar`: clock times, because the chat stories use `new Date()` (all 6 user-avatar shots differ, 014).
  - Hash noise: `navigation-sidenav--collapsed-vs-expanded` 360 light, `--sidebar-first-collapsed` 1024 light, `--collapsed-rail-badges` 360 light, `--sidebar-first-layout` 1280 dark. Table `--with-pagination`, `--with-filtering`, `--full-featured` at 1280 (random salaries, 022).
  - **"Hook at 0 restores" by hash (022):** inject `:root { --lc-x: 0 }` in `--measure` and re-shoot the intentionally changed stories `--full --compare=baseline`: 28/28 identical proved the opt-out exactly.
  - 010 r1: one 79-story `--compare` run hung after "`components-button--disabled-with-reason`: not rendered within 20 s" until the background limit. Split long compares into 3 parallel background batches with `timeout: 1800000` (474 shots in about 10 min). The story list can be built from the baseline logs with `grep -h -o '"story":"[^"]*"' … | sort -u | cut -d'"' -f4 | tr '\n' ','`, with no `cd`.
- **Line text in `--measure` (010):** group per-char Range rects by `top`, using `function T(n) { return n.nodeType === 3 ? [n] : [...n.childNodes].flatMap(T) }`. Hyphens from `hyphens: auto` are not in the DOM, so the char groups around them are unreliable; check hyphenated lines in the shot.
  - *All Icons* (5,093 fetches) sometimes ends with placeholders.
  - `data-display-document-viewer--image-preview` differs on every run (a random picsum image). `--compare` logs every shot with a `"compare"` key, so tally them with `grep -h -o '"compare":"[a-z-]*"' … | sort | uniq -c` (011). `node -e` prompts too, so compute contrast in `--measure` (canvas = `document.documentElement` background; body and story wrappers are transparent; regex `/[0-9.]+/g`, double quotes only).
- **Bundle shares without a rebuild (007).** Earlier fixture builds live in `tmp/00N/compat/bundle-next/dist/<config>`. `jq` over `browser-stats.json` gives `outputs[].inputs[].bytesInOutput`. To get a module's gzip share, cut its minified region in memory with `node -e` (zlib) and compare. In auto mode, `node -e`, `gzip` and `jq` ran without a prompt.
- **Headless runs started from life-os (009)** inherit `NX_WORKSPACE_ROOT_PATH=…/life-os`: every `npx nx run angular-ui-kit:*` prints "Cannot find project 'angular-ui-kit'", and the call shows up in life-os's daemon log. `unset`/`env` prompts, so report it as blocked. Fix (owner, 009): resume with `env -u NX_WORKSPACE_ROOT_PATH`. `printenv` prompts too; just run `nx run angular-ui-kit:build-storybook` as the check (about 18 s; the log shows only "1 task: 1 succeeded"). story-shots' mtime guard also trips after a checkout; `git diff <build commit> HEAD -- libs/angular-ui-kit/src` shows whether the build is really stale.
- **Prove "unchanged" before designing (010).** Inject the planned CSS in `--measure` (a `<style>` element, `;` as `String.fromCharCode(59)`), then run with `--compare=<baseline>`: 318 shots took a few minutes. `cd … ;` plus `>` in one command is refused, but cwd is already the repo, so drop the `cd`. For a consumer's font, load it as a `FontFace` from jsdelivr (`dejavu-fonts-ttf@2.37.3/ttf/DejaVuSans-Bold.ttf`). For recursion inside a measure, use `function BG(el) { return … }`. For contrast on translucent fills, composite over the first opaque ancestor.
- **Pending-image and transition probes (012; full measures in design 012 §9).**
  - A cloned `<img>` keeps showing its old image while a new `src` loads. To measure the box before load, use `createElement('img')`, copy the attributes, set a `?p=<random>` `src`, read the box at once and again after `decode()`.
  - story-shots emulates reduced motion, so transitions are 0.01 ms. Inject `.btn { transition-duration: 150ms !important }` and toggle a size class, then read `document.getAnimations()`.
  - Disabling the `.btn` `<style>` sheet changed nothing, so don't try that again.
  - Which files a lazy `<img>` fetched: `performance.getEntriesByType("resource").filter(e => e.initiatorType === "img")`. In Storybook light both theme drawings are fetched (the first frame is dark); check lazy-by-theme in dark. Count only `.btn` transitions (`a.effect.target`): the reduced-motion rule gives every `*` a 0.01 ms `all` transition.
- **Drawing variants (013).** In `--measure`, a block-bodied `(async () => { … })()` with one statement per line (ASI, no `;`) works. Fetch the served SVG, `.replace()` the `d` strings, show variants as `new Image(s, s)` with `URL.createObjectURL(new Blob([svg], { type: "image/svg+xml" }))` in a cleared `#storybook-root`; crop a 480 px face in an `overflow: hidden` box. `node -e` needs approval: compute in the measure. **Small-size check (013 r1):** draw the blob image on a canvas at native size (48/96), then `drawImage` the head region ×5/×10 onto a second canvas with `imageSmoothingEnabled = false`: one shot shows old vs new pixels in both themes (`013/r1-review/sheet`). Round derived px figures from unrounded values (4.015 × 0.96 = 3.85 → 3.9).
- **Whole-Storybook sweep in one shot (014).** In one `--measure`: `fetch("index.json")` → story ids, then per id `__STORYBOOK_ADDONS_CHANNEL__.emit("setCurrentStory", { storyId, viewMode: "story" })`, await `storyRendered` (8 s timeout), 250 ms, `axe.run(document, …)`. 897 stories took about 20 min per width (two widths in parallel). `axe.commons.text.accessibleText(el)` needs `axe.setup(document)` first (else "reading 'props'"), then `axe.teardown()`. axe source: `cdn.jsdelivr.net/npm/axe-core@4.14.0/axe.js`, fetch it in a measure to read a rule. The visible text as the label rule sees it: `axe.commons.text.sanitize(axe.commons.text.subtreeText(axe.utils.getNodeFromTree(el), { subtreeDescendant: true, ignoreIconLigature: true }))`. A collapsed (`aria-hidden`) region's name reads "", so click the header first. Use the Grep tool (`-o`, count) on several logs at once; a Bash `grep` over several files with `;` was refused (015).
- **Screen-reader pass (016).** `node tmp/story-shots/016/ax-pass.mjs <ids> [width]` works with no prompt. It reads the CDP `Accessibility.getFullAXTree` (role, name, description, required/invalid/live), presses real Tab keys and Enter on every link (mailto clicks are recorded, then prevented). It can't produce audible VoiceOver/NVDA, so name that limit in the review. **It prompted in 017, 018 and 040** (with and without a redirect; 040's real-input file-chooser script `040/r1-picker.mjs` too: in-page `click()` has no user activation, so a real picker open can't be shown through story-shots): fall back to `--measure` (tabIndex, `:focus-visible` after `focus()`) plus `--axe`, and name the limit. When story-shots calls a build stale and only a spec changed, an Nx cache hit leaves the dist mtime as it was; rebuild with `--skip-nx-cache`.
- **Resolving `var()` and hover rules (017).** Read `:hover`/`:active` values from `document.styleSheets` rules (`selectorText.startsWith(".btn-x:hover")`). Resolve each value on a **fresh** `div` every time: a reused probe returns the old colour, because the reduced-motion rule gives it a 0.01 ms transition. `node tmp/…/script.mjs` prompted in 017, so put long measures inline (newline-separated statements, no `;`); keep a copy in `tmp/story-shots/<NNN>/*.js`.
- **Element sweep (018).** The 014 loop without axe (`ch.once("storyRendered")` + 250 ms, collect `#storybook-root lc-alert` widths) covers 899 stories in about 6 min per width. The root `font-size` needs about 500 ms before a measure reads it. `design-tokens-density--side-by-side` at 1024 differs after any wait in a measure (time-dependent).
- **AX checks without the CDP script (018).** `016/ax-pass.mjs` prompted again. In `--measure`, load axe from jsdelivr and call `axe.setup(document)`. Then `axe.commons.dom.isVisibleToScreenReaders(el)`, which shows that `display: contents` keeps children in the tree, and `axe.commons.text.accessibleText(el)` for names, then `focus()` each control. An SVG's `className` is not a string, so read the role from the host. Overlap probe: text-rect right of the title vs the ×'s left edge. Contrast: `UP(el)` collects the ancestor backgrounds and `reduceRight` composites them.
- **Sticky checks need scroll room (019).** A story 1,083 px tall scrolls only 183 px, so "top 0 after 800 px" was never tested. Append a 2,400 px `div` to `main`, scroll, read, then remove it. Story frames with `overflow: hidden` clip collapsed-rail tooltips: list each ancestor's computed overflow before you call a tooltip missing. **Noise or change (019 r2):** re-shoot with `--compare=<old>`, `cmp` the result against the new run, and measure the computed colours. If the set of differing shots changes between runs and the colours are equal, it's raster noise.
- **Translucent tokens (020).** `--color-surface-selected` is rgba(32,132,151,.24) in dark (opaque in light): composite over the page before the WCAG formula, or hover text reads 3.21 instead of 10.57. A developer's compare folders can be checked with `diff -rq baseline <dir>` per folder (`cmp`, `cmp-full`, `cmp-rerun`), so only the flaky stories need a re-shoot.
- **At-rest references (021 r2).** Shots from a run whose `--measure` sorts, focuses or opens something are not at rest, so a later round can't `--compare` against them. Keep state-changing measures in a separate run from the at-rest run, and ask the developer's `new/` folder for every width the review will compare (021 had only 360/1280; 1024 had to be measured).
- **Hit tests (024).** `elementsFromPoint` at a rounded box's corner (radius 10) returns the parent: test edge midpoints, or centre ± 21.5 for a square `::before` hit area. `node -e` and heredocs (`cat <<EOF`) are refused; keep measure copies with the Write tool.
- **025.** An async arrow whose body starts with an IIFE needs outer parens, `async () => ((f)(x), await …, {…})`; without them the comma ends the arrow ("Unexpected token )"). Keep click-opened states (outlet stacks) in their own baseline folder (`baseline-open`) with the click in the measure, so the review re-shoots with the same clicks.
- **025 r1.** `if (x) …` lines and `for…of` blocks work in a newline-separated `--measure` (no `;`). axe `color-contrast` checks text only: measure icon-button colours (× in dark) yourself. Light shots of drawer form stories and NC 360 L flip between runs with equal measures: re-shoot against your own r1 before calling a diff real.
- **026 revert proof.** An injected `.lc-toast__close { color: buttontext }` (0,1,0) lost to the kit sheet re-inserted later; use `button.lc-toast__close` plus a 300 ms settle. A diff that is byte-identical across two post-change runs but equals an older build's shot (`025/after`) is a two-state raster flake, not a change.
- **028.** The Bash checker refuses `{a,b}`-shaped text in `--measure` ("Brace expansion"), e.g. CSS `.x{height:var(--h,0.75rem)}`: drop the comma inside the braces. "Identical SVG": hash `outerHTML.replace(/ _ngcontent-[a-z0-9-]+=""/g, "")` with `[...h].reduce((x, c) => (x * 31 + c.charCodeAt(0)) | 0, 0)`. Angular's `<!---->` block anchors are part of it, so a new nested `@if` inside the SVG changes the hash. **028 r2:** an escaped brace in a measure regex (`/x[^}]*\}/`) is refused ("backslash-escaped brace"); use `indexOf` + `slice`. `| tee`, and `sed` inside a `;` chain, prompt. This works: compare two logs' measures with `cat a b | grep -o '"measure":.*' | sort | uniq -u | grep -c <marker>`. Glyph ink in a measure: canvas `measureText(ch)` with the span's font, baseline = range top + fontBoundingBoxAscent + (h − fa − fd)/2.
- **029.** `node <file>.mjs` still prompts: compute contrast grids in a `--measure` on tokens resolved per theme (`tmp/story-shots/029/grid-measure.js`, run once on any story with `--themes=light,dark`). Prototype SVG presentation attributes and inline `style` colours with attribute selectors plus `!important` (`svg [stroke*=error-default]`, `.lc-kanban [style*=warning-default]`). A measure's element count can read 0 while the shot still changes (late render): wait 1.5 s before counting. **029 r1:** interpolate vertical `--gradient-surface` backgrounds at the element's y in the backdrop (NC high dark: 5.55 flat vs 4.97 real); script `tmp/story-shots/029/review-measure.js`. The static build has `window.ng` but no `ng.getComponent`: add files via `DataTransfer` on `input[type=file]` + `change`; half stars need `new MouseEvent("click", { detail: 1, clientX })`. One ~180-line `--measure` got "Parser aborted"; a shorter one ran.
- **Rule outcome, not just "0 violations" (031).** `--axe` lists only violations and incompletes, so prove `pass` vs `inapplicable` with CDN axe in `--measure`: `axe.run(document, { runOnly: { type: "rule", values: [RULE] } })` and count `passes`/`violations`/`inapplicable`. A negative control in the same measure: remove the nodes, re-run, then `insertBefore` them back (re-run = pass) so the shot stays at rest. `label-content-name-mismatch` in 4.14.0 is in `wcag21a`, not experimental. Save every arg-changing baseline measure as a `.js` in the shots folder; 031's `baseline-long` measure wasn't saved and had to be rebuilt (it matched by hash).
- **034 r1.** A Bash `grep -o` pattern containing `{` or `[^}]` prompts: match `.` instead of the brace, or use the Grep tool (`-o`). A developer's measure module served from the Storybook dist (`/zz-034/m.mjs`) can be `import()`ed inside `--measure`; review its logic before reusing it, then add only what it misses (034: diff viewer, markers, legend, placeholder, matches). Reusable review measure with gradient-aware backdrop: `tmp/story-shots/034/r1-measure.js`; state measure (open search, type, debug-line match vs main-with-opacity): `r1-state-measure.js`.
- **035 r1.** 15-story compare split in 2 background runs took about 1 min. A developer's measure module imported in `--measure` plus a short extra block (ring gaps, hook probes via `style.setProperty` then remove) covered a whole review in 4 runs; copy in `tmp/story-shots/035/r1-measure.js`.
- **036 r2.** An object literal `{a: 1, b: 2}` in `--measure` is refused as "Brace expansion": return `Object.fromEntries([["a", x], ["b", y]])` from expression-bodied arrows (`(h => (a => …)(…))(el)`), with no braces at all.
- **039 r1.** Group semantics proof: CDN axe `runOnly` rules + `axe.commons.aria.getRole(dt/dd)` (term/definition) in one measure; avoid `#` with `getElementById("storybook-root")`. A review with 6 runs (rest compare, 4 story groups, FC) took ~10 min; the developer's `build-*` folders re-checked by `diff -rq` instead of re-shooting 396 shots.
- **041 r1 accessible name/description without CDP:** in `--measure`, `await import("https://cdn.jsdelivr.net/npm/dom-accessibility-api@0.7.0/+esm")` → `computeAccessibleName/Description(el)` (jest-dom's engine, on the real page). After a 1.5 s wait, `window.__STORYBOOK_PREVIEW__.storyRenders[].phase === "finished"` shows the play function passed. Chrome's `computedName` is not exposed. Measure copy `041/r1-button-measure.js`; whole review in 3 parallel runs (~2 min) plus `diff -rq` on the developer's compare folders.
- **042 focus sweep + hover emulation.** One `--measure` walks all 997 stories (`setCurrentStory` loop), focuses every focusable (dedupe per story by host+class), diffs computed outline/shadow/border/bg of el + 3 ancestors + siblings + children before/after focus: ~5 min per width/theme (`042/sweep-measure.js`). `[contenteditable]` has `tabIndex -1`, so add it explicitly. Hover: clone every `:hover` rule with `:hover`→`.zh` via `insertRule` right after the original (same specificity and order), then toggle `.zh` on the ancestor chain (`042/hover-measure.js`). `{ try { return f() } catch (x) { return 0 } }` (no comma inside braces) passes the brace checker. `story-shots --list` (no `=`) prints all ids; `--list=` fails.
- **042 r1 measure traps.** `await` needs an `async` arrow and must not sit in its default params ("Illegal await-expression in formal parameters"): put awaits in the body. Focus-then-read in one task returns 3px currentColor outlines: the reduced-motion rule (`transition-duration: .01ms !important`, property `all`) animates every element; wait a rAF. Rule scans: every CSSStyleRule has `.cssRules`, so flatten only rules without `selectorText`; `var()` in a shorthand leaves `rule.style.outlineStyle` empty, so match `cssText`. Generic per-shot ring measure (activeElement ring, contrast, room, opacity) + dev modules `/zz-042/{dep,fu}.mjs`: `042/r1-new-measure.js` (move the awaits into the body). At-rest compare of 1,090 shots in 4 parallel runs ≈ 12 min.
- **043.** CSS with commas inside braces (`min(0px, …)`) in a measure: write `OPEN`/`CLOSE` and `.replaceAll("OPEN", String.fromCharCode(123))`; `content: attr(data-zz)` replaces `content: ''` inside the single-quoted measure. Subtree-theme prototype: copy the root rule's colour declarations from CSSOM (`selectorText.startsWith(":root, :root.light")`) into a new rule (`043/proto-all.js`, `header-proto.js`). `until grep -q '<last shot name>' log; do sleep 10; done` waits without a prompt; `test "$(…)"` is refused. **043 r2:** brace-free hit-area scan (real ::before extent): `ext = (x, cx, cy, dx, dy) => [...Array(61).keys()].map(i => i * 0.25).find(k => !hit(cx + dx * k, cy + dy * k, x))`, area `new DOMRect(…)`; reads 13/12 for a 24 px area (±1 px snapping), so judge overlaps with that margin (log `043/r2r-tag-tt.log`). A trailing `rmSync ENOTEMPTY` crash of story-shots after the last shot is harmless, but the summary line is lost.
- **044.** In-place CSSOM prototype: flatten `document.styleSheets`, match `selectorText.replace(/\[_ngcontent-[a-z0-9-]+\]/g, "")`, `rule.style.setProperty(…)`, `insertRule(text + attr, indexOf(rule) + 1)` for a new rule, then clone `:hover` rules (`044/filled-proto-measure.js`, default-param style, states via class/prop toggles + 250 ms waits). `updateStoryArgs` ignores args the story didn't declare; toggle classes/props in the DOM instead. Files into an `<input type=file>`: `DataTransfer` + `change` (`044/chat-pending-measure.js`, canvas `toBlob` for a stable PNG).
