- **Default DOM identity:** prove it once per request with a temp spec (`tmp/056/zz-056-old-new.spec.ts.txt`): `git show main:<html> > tmp/<NNN>/old/`, `TestBed.overrideComponent(C, { set: { template, templateUrl: undefined } })`, compare `outerHTML` without comments, `_ng*` attrs, `id="rootN"` and counter ids. Only comment anchors may differ (one per `@if`/`@switch` branch).
- **Whitespace in templates:** Angular drops whitespace-only text nodes (also `<span> </span>`) and keeps a single space inside text with interpolation; a separator must be `&ngsp;`. An `&ngsp;` right after an `@if…}`/`@for…}`/`@defer…}` chain (only whitespace/comments before the next element) is swallowed by `findConnectedBlocks` (looking for `@else`): put it inside each branch, e.g. after a `@switch…}` (058).
- **Edit/Write tools turn ` ` in parameters into the literal char** (lint `no-irregular-whitespace`): write `String.fromCharCode(0xa0)`; to fix a literal, pass ` ` in `old_string`. A `[input]` binding that replaces a static `input="x"` drops the host attribute from the DOM.
- **axe 4.14 `label-content-name-mismatch`** reads visible text with `visibleVirtual`: text nodes joined with no separator and no layout, so jsdom = Chromium (card title + body, list label + badge run together). Check every designer "passes" for multi-part controls. Fix that keeps the default DOM byte-identical: `{{ sep(item) }}{{ text }}` in one text node (`sep` = `' '` only when named); a leading space renders nothing at a flex item's line start (059). Injecting a component's compiled CSS into jsdom can make the rule `inapplicable`.
- **Attribute order:** static non-class attributes render before `class` (`role="alert" class=…`); bindings come after (properties before `[attr.*]`, template order). A new conditional static attribute keeps the order with `@if {static} @else {without}`.
- **Jest/jsdom:** `[class]` lists classes sorted; `TestBed.configureTestingModule` twice per test throws (create a standalone host with `TestBed.createComponent`); fake `ResizeObserver`/canvas as in `src/testing/axe-jsdom.ts`; jsdom applies no component CSS (append compiled SCSS to `head` for axe/visibility); a `--testFile` run with no Jest output: rerun once (or add `--output-style=static`). Full suite: `--maxWorkers=4` (check `uptime`; on a SIGSEGV run that suite alone). `it.each` rows shorter than the callback's arity make Jest pass `done` ("called multiple times"): wrap the row as one argument. Sass writes `max(0px, calc(a - b))` as `max(0px, a - b)` (pin the compiled form).
- **Storybook:** args left out of `parameters.controls.include` arrive `undefined` in a custom `render` (blank story): include them or pass data as constants. Story props named like non-input members overwrite the component (use `seedX`). Preview HTML has 2 hidden `h1` (`.sb-nopreview`, `.sb-errordisplay`): count headings inside `#storybook-root`. `play` runs before the shot; `userEvent.keyboard('{Enter}')` after `focus()` gives keyboard modality (`:focus-visible`). Shots are DPR 2 (`srcset` picks the 2x candidate); SVG stand-ins must keep the exact ratio (`aspect-ratio: auto w/h` switches to the natural ratio on load). A `scroll-snap-type: x mandatory` row snaps its first item to x 0 unless `scroll-padding-inline` matches the padding. **Story review findings (059 r1):** a sideways scroller with no focusable child fails axe `scrollable-region-focusable` (wrap, or a named `tabindex="0"` region); a row that bleeds to the page edge needs its ring at `outline-offset: -2px`; German `alt`/text goes in a `lang="de"` wrapper (no pixel change). Dropping `overflow` on a wrapper un-clips shadows/AA corners (Δ ≤ 2 hash diffs, same geometry).
- **Whole-file SCSS pins** (`createHash` of compiled CSS: dl `wrap`, earlier alert): append new rules at the file end and cut them off before hashing (`css.search(/\s*\nfirst-new-selector \{/)`), keep the pinned values, list as a deviation. Prefer per-rule pins in new specs. Compiled lists use `,\n  `: match with `,\s*`.
- **Higher-weight reset rules:** `:last-child { border-bottom: 0 }` (0,4,0) beats a new row modifier: write the modifier rule at the same weight after it. `[hidden]` loses to an author `display: flex`: add `.x[hidden] { display: none }`. **lc-badge host** is inline: as a flex item it becomes a 25 px block (line box); `display: inline-flex` makes it the 24 px badge box.
- **Entry graph:** a new folder = stub + `index.ts` + `src/index.ts` line + `entries.spec.ts` count + `tools/compat/check-entries.mjs` count (then `test:tools`). Cross-folder imports by package path; specs/stories may import relatively.
- **Lint:** an element with `(keydown)` that delegates to focusable children trips `interactive-supports-focus` (error): house comment `<!-- eslint-disable-next-line … -- reason -->`. Non-null `!` in specs adds warnings: cast instead.
- **Icons:** a kit component that renders a glyph itself needs `viewProviders: [ɵprovideKitIcons([ICON_X])]` (scoped, parent registry still used).
- **theme-contrast:** pin floored values; design §5 quotes rounded ones (0.01 apart), note it.
- **Shared tree:** commit early on the branch (WIP, amend later); stage by name; `requests/BACKLOG.md`/`README.md` edits belong to the release commit.
- **Designer hypotheses / measured values can differ** (proto CSS not stored): measure first, record the difference as a deviation.

**Why:** none of these show in the code; each cost a debug round.
**How to apply:** check this list before debugging a spec, story or shot diff; add new traps compactly.
