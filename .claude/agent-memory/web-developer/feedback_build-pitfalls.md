- **Default DOM identity:** prove it once per request with a temp spec (`tmp/056/zz-056-old-new.spec.ts.txt`): `git show main:<html> > tmp/<NNN>/old/`, `TestBed.overrideComponent(C, { set: { template, templateUrl: undefined } })`, compare `outerHTML` without comments, `_ng*` attrs, `id="rootN"` and counter ids. Only comment anchors may differ (one per `@if`/`@switch` branch).
- **Whitespace in templates:** Angular drops whitespace-only text nodes (also `<span> </span>`) and keeps a single space inside text with interpolation; a separator must be `&ngsp;`. An `&ngsp;` right after an `@if…}`/`@for…}`/`@defer…}` chain (only whitespace/comments before the next element) is swallowed by `findConnectedBlocks` (looking for `@else`): put it inside each branch, e.g. after a `@switch…}` (058).
- **Edit/Write tools turn ` ` in parameters into the literal char** (lint `no-irregular-whitespace`): write `String.fromCharCode(0xa0)`; to fix a literal, pass ` ` in `old_string`. A `[input]` binding that replaces a static `input="x"` drops the host attribute from the DOM.
- **axe 4.14 `label-content-name-mismatch`** reads visible text with `visibleVirtual`: text nodes joined with no separator and no layout, so jsdom = Chromium (card title + body, list label + badge run together). Check every designer "passes" for multi-part controls. Fix that keeps the default DOM byte-identical: `{{ sep(item) }}{{ text }}` in one text node (`sep` = `' '` only when named); a leading space renders nothing at a flex item's line start (059). Injecting a component's compiled CSS into jsdom can make the rule `inapplicable`.
- **Attribute order:** static non-class attributes render before `class` (`role="alert" class=…`); bindings come after (properties before `[attr.*]`, template order). A new conditional static attribute keeps the order with `@if {static} @else {without}`.
- **Jest/jsdom:** `[class]` lists classes sorted; `TestBed.configureTestingModule` twice per test throws (create a standalone host with `TestBed.createComponent`); fake `ResizeObserver`/canvas as in `src/testing/axe-jsdom.ts`; jsdom applies no component CSS (append compiled SCSS to `head` for axe/visibility); a `--testFile` run with no Jest output: rerun once (or add `--output-style=static`). Full suite: `--maxWorkers=4` (check `uptime`; on a SIGSEGV run that suite alone). `it.each` rows shorter than the callback's arity make Jest pass `done` ("called multiple times"): wrap the row as one argument. Sass writes `max(0px, calc(a - b))` as `max(0px, a - b)` and same-unit `calc(2rem - 0.25rem)` as `1.75rem` (pin the compiled form). Pseudo-box-inside-scroller measure (margins at scroll 0/end, bar px): `tmp/065/measure/r3.mjs`.
- **Storybook:** args left out of `parameters.controls.include` arrive `undefined` in a custom `render` (blank story): include them or pass data as constants. Story props named like non-input members overwrite the component (use `seedX`). Canvas padding 16 + hero padding 20: a `[hero-media]` column is 288 at 360 px; a design that assumes 320 needs `layout: 'fullscreen'` + `borderRadius="none"` (060). Preview HTML has 2 hidden `h1` (`.sb-nopreview`, `.sb-errordisplay`): count headings inside `#storybook-root`. `play` runs before the shot; `userEvent.keyboard('{Enter}')` after `focus()` gives keyboard modality (`:focus-visible`). Shots are DPR 2 (`srcset` picks the 2x candidate); SVG stand-ins must keep the exact ratio (`aspect-ratio: auto w/h` switches to the natural ratio on load). A `scroll-snap-type: x mandatory` row snaps its first item to x 0 unless `scroll-padding-inline` matches the padding. **Story review findings (059 r1):** a sideways scroller with no focusable child fails axe `scrollable-region-focusable` (wrap, or a named `tabindex="0"` region); a row that bleeds to the page edge needs its ring at `outline-offset: -2px`; German `alt`/text goes in a `lang="de"` wrapper (no pixel change). Dropping `overflow` on a wrapper un-clips shadows/AA corners (Δ ≤ 2 hash diffs, same geometry).
- **Whole-file SCSS pins** (`createHash` of compiled CSS: dl `wrap`, earlier alert): append new rules at the file end and cut them off before hashing (`css.search(/\s*\nfirst-new-selector \{/)`), keep the pinned values, list as a deviation. Prefer per-rule pins in new specs. Compiled lists use `,\n  `: match with `,\s*`.
- **Higher-weight reset rules:** `:last-child { border-bottom: 0 }` (0,4,0) beats a new row modifier: write the modifier rule at the same weight after it. A hidden-at-rest `.row .btn { opacity: 0 }` beats the button's own `:focus-visible` (sidenav row actions invisible on focus since 3.0, 067 F-1): put every reveal state under the row selector; measure opacity focused/expanded with `tmp/067/measure/r2.mjs` (a measure's `focus()` matches `:focus-visible`). `[hidden]` loses to an author `display: flex`: add `.x[hidden] { display: none }`. **lc-badge host** is inline: as a flex item it becomes a 25 px block (line box); `display: inline-flex` makes it the 24 px badge box.
- **Entry graph:** a new folder = stub + `index.ts` + `src/index.ts` line + `entries.spec.ts` count + `tools/compat/check-entries.mjs` count (then `test:tools`). Cross-folder imports by package path; specs/stories may import relatively.
- **Lint:** an element with `(keydown)` that delegates to focusable children trips `interactive-supports-focus` (error): house comment `<!-- eslint-disable-next-line … -- reason -->`. Non-null `!` in specs adds warnings: cast instead.
- **Icons:** a kit component that renders a glyph itself needs `viewProviders: [ɵprovideKitIcons([ICON_X])]` (scoped, parent registry still used).
- **theme-contrast:** pin floored values; design §5 quotes rounded ones (0.01 apart), note it.
- **Shared tree:** commit early on the branch (WIP, amend later); stage by name; `requests/BACKLOG.md`/`README.md` edits belong to the release commit.
- **Designer hypotheses / measured values can differ** (proto CSS not stored): measure first, record the difference as a deviation. Designers often measure the inner label; measure the host too (`lc-checkbox` md: label 26, block host 27 from the line box; 061).
- **062:** `lc-menu` never opens on its own trigger click: the page binds `[isOpen]` + `(closed)`. A checkbox `(click)` `preventDefault()` blocks the toggle in jsdom and Chromium (Space, label click; indeterminate kept). Chromium prefers a space break over hyphenation: a long German compound after a short word moves to the next line first (select header 3 lines, designer prototype said 2). Changing a component's `font: inherit` size shows in hero stories at 1280 only (hero body 16 px there). **Forced colours (062 r1 must-fix):** backgrounds become Canvas but an SVG's own `color` survives, so a state glyph (check, dot as background) vanishes; any glyph that carries state needs `@media (forced-colors: active)` with `CanvasText`/`GrayText` + `forced-color-adjust: none`, at the weight of the strongest colour rule, shot with `--forced-colors`. `npm run generate:icon-names` and `node scripts/…` stay refused: hand to the release-manager, don't wrap them.
- **063:** wrapping a value in a hook (`var(--lc-x, <old>)`) breaks specs that pin the literal (theme-contrast alert icon/tint regex, icon `width: 16px`, close-target colour); a new token bumps `theme-modes` counts (173/253 now): update with the same rest value and list them. Specs compile to ES2016: no BigInt literals (`BigInt(10)`), and big number literals fail lint `no-loss-of-precision`. `<style>` in a story template is emulated: `:root…` selectors need `::ng-deep`. `lc-textarea` host has a 6 px inline-block gap under the field (affects end-aligned neighbours; one-line mode is `display: block` since 063 r2). **Changing a rule a request added: grep `tools/compat` for its selector**: `EXPECT_IN_HTML` pins whole rules (`\{\s*min-height:\s*0;?\s*\}`), so a new declaration fails compat silently until the compat run.
- **064:** an `@if` anchor comment sits *after* its content, so a separator text node after an `@if`-wrapped element is no longer its `nextSibling` (stat-trend S1 pins): render the following part via `ngTemplateOutlet` inside both branches. A static attribute that feeds a directive input (`tooltipPosition="top"`) still renders in the DOM: bind it or omit it. Specs that read `css.lastIndexOf('@media (forced-colors…')` (list split-row) or the first `\n.sel {` (tabs nested rules, modal `sheetRule('')`): put new forced-colours rules into an earlier block at higher weight, new placement rules after the pinned ones. A component that starts importing `IconComponent` gets its string literals scanned by `kit-icons.spec.ts` (add `NOT_ICONS` entries such as variant names). A sidenav spec needs the full `matchMedia` mock (`addListener` too: axe/CDK call it). `--outputFile` of the lint target wrote nothing: use `--quiet` into a log and grep `problems`. **064 r1 review traps:** forced colours turn a `transparent` border into the text colour (every tab looked selected): set rest borders to `Canvas`, the state to `CanvasText`; hidden sr text on the sidenav rail must lead with the label (labels are `display: none`, `title` stops naming once content exists); an `inline-flex` host in a stretching flex row stretches its group (host `align-items: flex-start`); a wrapped text node beside an icon is an anonymous flex item that centres its lines (`text-align: start`); story rows `fixed nav + flex: 1 text` overflow at 360 (`flex-wrap: wrap`). **r2:** a `.ctx &` nested in `&--mod` compiles before a later `.ctx &` block of the same weight, which then wins (vertical tabs had no selected line since forever): write `.ctx &--mod {}` after the context block; prove a pin by running it on `git show HEAD:<scss>` (fails) and restoring.
- **065:** story-shots `--axe` runs axe's *experimental* `label-content-name-mismatch`; the jsdom `audit` doesn't (experimental off unless `LABEL_IN_NAME` is passed): a listbox option named by its label only while it shows hint/shortcut text fails in shots but passes units. Test new multi-part options with the rule on. A `@container` rule can't style its own container: put `container-type` on the host via `.host:has(> .x)` (pure CSS, no host class). Sass merges nothing in `container-name`/`container-type` longhands (the shorthand compiles to `lc-tabs/inline-size`). Specs pinning a focus-ring count (`sidenav.brand` `outline: 2px solid` ×N) or "no later `border-right`" (tabs.links) move when a rule is added: say why in the assertion.
- **065 r2:** `_utilities.scss` sets `transition-duration: 0.01ms !important` on `*` under reduced motion (shots always emulate it); with the initial `transition-property: all` *every* style change animates for a frame, so a layout read right after a DOM change (scroll pinning) sees old paddings: `transition-property: none` on that element. lc-modal sets `body { overflow: hidden }`: in jsdom (0 × 0 rects) axe then counts everything inside as hidden and rules go `inapplicable` silently; set `overflow: visible` on body (and clipping wrappers) before auditing. Index-based ids change when rows are inserted above: read "before" under the old id. `Array.prototype.at` passes Jest but fails the lib build (TS2550).
- **065 r3 (M6):** Chromium's `focus()` doesn't scroll a *partly* visible element inside an `overflow` scroller: any roving focus in a scroller needs `(focus)` → `scrollIntoView?.({ block: 'nearest', inline: 'nearest' })` + `scroll-margin` = the ring/box outset. Spy in Jest via `Element.prototype.scrollIntoView = jest.fn(function (this) …)`, then `delete` it.
- **066:** selector scoping is provable in jsdom: extract every compiled selector, unwrap `:where()`, drop `:pseudo`, `querySelectorAll` it on the rendered nested DOM and check the match's own `closest(root)` has the selector's first-compound modifiers (take modifiers after stripping `:not()`); run it on the old SCSS to show it fails. A leading icon beside a *right-aligned wrapping* flex text: the text box fills the row, so box gap 4 ≠ visual gap (13–70 px to line 1's first glyph); measure glyph rects (Range), not boxes, and flag it to the designer (fix D-6: inline `nowrap` row + `white-space: normal` text + icon `margin-inline-end`; the icon's width must be added to any `min(100%, Nem)` basis, D-7; measure module `tmp/066/measure/r1.mjs`). Angular ships component CSS unscoped in fesm (`:where()` chains survive minified); the `_ngcontent` shim runs in the consumer.
- **067:** `lc-menu` mirrors `aria-haspopup`/`aria-expanded` onto its projected `[trigger]`: a `<span trigger>` fails axe `aria-allowed-attr`; to anchor an app menu at a kit button use no trigger, a `position: fixed; display: flex` box as high as the button at its right edge and `<lc-menu style="display: flex">` (else the empty inline-block line box puts the panel 32 px low, not 8). In SVG `<text>` with `@if` branches the last child is a comment anchor: read text nodes in specs. `linkedSignal` tracks reads in `computation` too (wrap extras in `untracked`). An always-rendered empty slot wrapper changes `aside.children` pins (brand spec): update with the design's reason. `notification-center.icons.spec` flakes under load (items with `new Date()` ties): rerun alone.
- **Group/child signal sync:** an effect that sets a child's `checked` from the group only reruns on its own deps; to make the group win over a later `[checked]` binding, read `checked()` in the effect too (061). A story export named like an imported class (`FormControl`) needs an import alias to keep the story id.

**Why:** none of these show in the code; each cost a debug round.
**How to apply:** check this list before debugging a spec, story or shot diff; add new traps compactly.
