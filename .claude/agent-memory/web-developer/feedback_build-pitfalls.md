---
name: feedback-build-pitfalls
description: Traps hit while building kit changes (Jest fakes, compat/CSP fixtures, Storybook, entry graph, SCSS specs, flex layout in lc-header, API breaks via model())
metadata:
  type: feedback
---

- **Jest:** a fake `window.trustedTypes` must pass `angular*` policies through (JIT). `lc-icon` names outside the inline set are fetched: register a fake glyph (`provideLcIcons`). An `@if` around a projected element projects its anchor (empty-slot tests need a host without it). Host `[class]`/`[style]` order differs: compare sorted. A header without `homeHref` needs `provideRouter([])`. jsdom: `:empty` ignores Angular's comment anchors; global RO is a no-op stub (swap `global.ResizeObserver` per test, `await fixture.whenStable()` runs `afterNextRender`).
- **Compat fixtures:** no kit `<div>` inside `<p>` (NG0502). Strict CSP only in the template's `csp` config. Empty attrs are bare on 21/22.0, `=""` on 22.2 (`emptyAttr()`; run `--only=22.0` for a new HTML check). Component CSS is inlined per page with spaces kept (`max( calc(…)) ,`): use `\s*` and name the page.
- **Storybook:** with `component` in meta, every story prop that is not an input is copied onto the story component instance (wrapper `ngAfterViewInit`): a template prop named like a member (043 r1: `tags` vs the tag-input `tags` signal) breaks the component silently; name seed props `seedTags` etc. Story `applicationConfig` providers win over preview's. A story `<style>` is Emulated: `::ng-deep html:has(#storybook-root [data-x="200%"]) { font-size: 200% }` raises the root text. Stories-only edits: `build-storybook --skip-nx-cache` (else it restores "[local cache]" without them; 042 r1). Old stories pass `iconBefore`/`variant="text"|"outlined"` to `lc-button`: neither exists (empty button, glyph in `buttontext` black, 1.46:1 dark); use a projected `<lc-icon slot="icon-before">` + `ariaLabel` and a real variant (`ghost`).
- **Entry graph:** `import type` and `import()` count as entry deps (cycles); `from '@lifecorner/…'` in comments trips `entries.spec.ts`. A new entry (even `internal/*`) also needs the list in `entries.spec.ts` and the hard-coded count in `tools/compat/check-entries.mjs` (CI), so `tools/` changes → `test:tools`.
- **Test-only helpers (015):** `src/testing/axe-jsdom.ts` is shared by the `*.axe.spec.ts` (canvas stub, `audit`, `outcomeFor`, `computedName`). A non-spec file under `src/` that imports a devDependency fails lint (`@nx/dependency-checks` wants it in peerDependencies): it is in that rule's `ignoredFiles`. `&ngsp;` (kept space) works in JIT, Storybook and the partial build; whitespace-only text in a flex/block parent renders nothing.
- **`@property` in component SCSS (038):** passes Angular's style shim unscoped, survives the fesm and the SSR-inlined page CSS (compat regex `@property\s+--_…\s*\{`). Sass emits `syntax: "<…>"` (double quotes). Specs that list "every selector after the cut" see the at-rule as a selector: skip exactly that name. Register a private `--_lc-…` name, not the public hook (keeps its token default and type).
- **Sass** drops a `calc()` nested in `max()` (`max(0px, (a - b) / 2 - …)`): assert the compiled text, not the source. A design that changes a mechanism (grid → flex, `break-word` → hook) breaks old SCSS-text assertions despite "specs not edited": change them to the stronger form and list each in build.md.
- **Compiled-CSS regexes:** anchor at `\n.selector {` — `/\.hero__body \{…opacity/` first hit `.hero--light .hero__body` (.75, not .85) in 017. Contrast specs can read real values from another folder's SCSS via `compile(resolve(__dirname, '../hero/…scss'))` (not an import, so no entry-graph edge).
- **Specs on SCSS text** break when rules move; new tests go in `<name>.<topic>.spec.ts`. `test:tools` needs story templates as top-level helpers with defaults, not method calls.
- **API break trap:** `x = model()` replacing `xChange = output()` drops the class member; keep `readonly xChange: OutputRef<T> = this.x`.
- **Flex rows that must stay pixel-identical (request 009, lc-header):** a `min-height` on an item holding an `<img>` re-centres it and resamples the logo sub-pixel; put the row's min-height on a zero-width sibling. Border-box `min-height` 64 with a 1 px border → item min-height 63. A wrapped group centring its items needs `align-self: stretch`. An `::after` with flex-shrink 1000 collapses whenever any sibling overflows. Line breaking uses outer hypothetical sizes, so a negative inline margin on a child is the only way to take a gap off a `min-content` basis. Probing `flex:none; width:min-content` on an item of a wrapping row returned the grown size: trust the arithmetic or the shot diff.
- **(032)** Angular serialises a `[style]="{width, height, 'border-radius'}"` map as `border-radius; height; width` (not key order): pin the real string. The spec's "change these assertion lines" list missed a sibling spec (`skeleton.height.spec.ts` circle row): grep the folder's specs for the old value before trusting an AC's line list, and record the extra change as a deviation.
- **Misc:** headless Chrome in CI needs `--no-sandbox` when `CI` is set. `lc-skeleton` % widths applied once since 3.22.2 (before they compounded). Writing `﻿` via file tools gives a literal BOM (lint). In `<pre>` write control flow without whitespace. Regex attr parsers: names have digits (`x1`); count tags. The Edit tool trims a `new_string` of just `" "` to empty (joined attributes in 011): anchor edits on a neighbouring word. A CSS-text count of `overflow-wrap: anywhere` also hits `--lc-btn-overflow-wrap: anywhere`: match `\soverflow-wrap`.
- **Compat work dir:** `check-angular-majors.mjs --only=22 --work=<scratchpad>/compat` (outside the repo, so node resolution can't fall back to the repo's node_modules), then `check-trusted-types.mjs --app=<that>/app-22` runs without approval (~1 min).
- **Attribute order (012):** Angular applies all property bindings before attribute bindings, attributes in template order; to put `loading` before `src` bind `[attr.src]` after `[attr.loading]` (still URL-sanitised). `getAttributeNames()` shows insertion order: set inputs before the first `detectChanges()` when a spec pins it. A static input on a component host (`<lc-avatar loading="lazy">`) also stays as a host attribute.
- **Transition probes (012):** story-shots emulates reduced motion, so the global `* { transition-duration: 0.01ms !important }` makes every element (initial `transition-property: all`) show up in `getAnimations()` (e.g. `font-size@LC-ICON`): filter by target. Toggling and reading boxes one element at a time reads half-toggled layouts: toggle all, then read.
- **Story-only review round (012 r2):** lint + `test:tools` + `build-storybook` + shots suffice (no spec imports logo stories; only `code-block` reads a story); don't run the lib build, it makes story-shots refuse the Storybook build. `review.md` goes in the release commit (011 precedent), not in the fix amend. A custom-src story in dark needs a dark partner file (mono emblem was 1.06:1).
- **axe-core in Jest (014):** `import * as axe from 'axe-core'` (esModuleInterop is off); jsdom has no 2D canvas, so `label-content-name-mismatch` errors into `incomplete` unless `HTMLCanvasElement.prototype.getContext` returns a fake (measureText 10 px/char, fully inked `getImageData`); disable `color-contrast`, `target-size`; `axe.setup/teardown` around `commons.text.accessibleText`.
- **Shared working tree (016):** a parallel headless pipeline switched the branch to `main` and rebuilt Storybook mid-run. Commit early on your branch, check `git branch --show-current` and `git diff --quiet <commit> -- libs tools` before each gate. Grep specs repo-wide incl. top-level `src/lib/*.spec.ts`: `i18n-labels.spec.ts` asserts every component's `aria-label` inputs (missed by a per-folder grep).
- **Inventory specs (018):** `button.overflow-wrap.spec.ts` pins the exact list of stylesheets setting `--lc-btn-overflow-wrap` and the "The kit sets it in …" sentence (button + button-link JSDoc, button-link argType): a new setter updates all four; designers miss it. Compiled CSS starts at index 0 (no `\n` before the first rule); a selector-list rule `.a,\n  .b {` contains `  .b {`: check the text before a hit ends in `{`/`}`.
- **(019 r2)** Story frames side by side: `overflow: visible` lets a collapsed sidenav's tooltip out, but the next `lc-sidenav` (its own stacking context) paints over it. A clip-ancestor check misses that, so look at the shot; stack the frames with `position: relative; z-index` descending. Dropping a rounded `overflow: hidden` also changes icon anti-aliasing (Δ ≤ 40). Angular whitespace: putting an element right after `{{ x }}` drops the collapsed trailing space of the default text node (" +3.1% " → " +3.1%"); keep the default with `@if (…) { {{ x }}<span…> } @else { {{ x }} }` and pin `textContent` untrimmed.
- **(020) Moving CSS-var defaults off `:host`** (ancestor-settable hooks): grep every spec for the old `--lc-x: …` declaration text repo-wide; the designer's list missed `sidenav-placeholder.component.spec.ts`. A `0` in a calc-fed custom property must be `0px`. A new compat probe goes on the home page (`home.ts` import + `home.html` tag); check regexes with ids + lookaheads, since several headers/avatars share the page.
- **(022)** `kit-icons.spec.ts` reads every quoted kebab literal in component `.ts` as an icon name, CSS selector strings too (`[role="link"]` → "'link' needs link"): write unquoted attribute values (`[role=link]`). A clipped sr-only span (`position: absolute`) in an inline host inside a scrolling table escapes the scroll box and widens the page (575 px at 360): give the host `position: relative`. Story `overflow-x: auto` divs need `tabindex="0" role="region"` + a name (axe `scrollable-region-focusable`).
- **(021)** Eager test host + plain fields mutated between `detectChanges()` → NG0100: make host state signals. `:not(a, b)` selectors break `selector.split(',')` in style specs: split with `/,(?![^(]*\))/`. A `cellClass`/story-class colour on `lc-table` cells loses to the kit's `td` rule (0,5,3): read the computed colour before trusting a story's colour. Review rejects a story `::ng-deep … !important` override (it teaches consumers to override the kit): colour cells with `cellStyle` (inline) instead. 200 % root-text measures need ~600 ms (`setTimeout`), two rAFs read stale widths.
- **(023)** Clicking a `routerLink` in a spec with `provideRouter([])` to an unknown route rejects (NG04002) and kills the Jest worker once later tests run ("4 child process exceptions"): `jest.spyOn(TestBed.inject(Router), 'navigateByUrl').mockResolvedValue(true)` first. Prove a fix's test by reverting the template line once (it must fail).
- **(024)** `lc-toast` is `ViewEncapsulation.None`: its `:host { display: block }` is dead, so a toast outside a flex parent is `inline` and a story wrapper `div` breaks its card (put `lang` on the toast). `encapsulateStyle(css, 'c1')` from `@angular/compiler` proves emulation scoping in Jest (it scopes inside `:where()`; spaces are tripled). An `ngModel`-fed `lc-select` shows its value only after `await fixture.whenStable()`. Menu stories render open (`isOpen: true`): menu style changes differ "at rest". 30 `lc-icon` sites still lack `decorative` (log-viewer, document-viewer, gallery, combobox, file-upload, field-group).
- **(025)** TestBed renders a root component into a `<div>`, not its selector tag: to test an element selector (`lc-toast:not(lc-toast-outlet lc-toast)`) use host components and `el.matches()` (jsdom handles complex `:not()`). A CSS check for `\bwhite\b` hits `white-space`: match `:\s*white\b`. `git stash push -- <paths>` needs approval: prove a test by reverting a line with Edit.
- **(026) "Only the colour changed" revert proofs:** an injected revert `<style>` in `--measure` reads right in `getComputedStyle` but the shot still paints the new colour after two rAFs: wait 300 ms + rAF before returning (`tmp/026/measure/open.mjs`), and use a (0,1,1) selector (`button.x`), since a component's stylesheet can land after yours. story-shots prints `"compare":"different"` (not "differs").
- **(028) Function args in stories:** without an argType for it, Storybook never delivered `CustomFormat`'s `formatValue` arg (the shot showed the defaults, unnoticed since the story existed); declaring an argType (`control: false`, description, default) delivered it, so a new argType can change an "unchanged" story's shot. Check a story's rendered text, not just that it renders. A spec helper named `one` was shadowed by a local `const one` (TypeError): give test locals distinct names. `sed -i` needs approval: edit temp copies with Edit.
- **(029) Nested parent selectors invert:** `.x { .a & { .b & { … } } }` compiles to `.b .a .x` (`.b` outside `.a`), so a "variant then modifier" block was dead for years (log-viewer terminal levels). Write the chain in one line, `.a .b & { … }`, and pin the compiled selector in a spec. When a measure groups by variant, measure *every* variant the rule names (r1 skipped `--terminal` levels and missed it).
- **(030) Icon generator headless:** `npm run generate:icon-names` (and `node scripts/…`) needs approval. A temp Jest spec with the generator's `compact`/`tsString`/`constantName` writes the snippets to `tmp/<NNN>/gen/` (sanity: it reproduces a committed glyph), paste with Edit; `icons.spec` + a `compact(Tabler)` spec prove it. Story descriptions must be static strings (`${x}` reaches the MCP literally). `lc-notification-center` and `lc-filter-bar` embed `lc-search-input` (its glyph fix shows in their specs). Every log-viewer story has pre-existing axe `color-contrast` (debug lines) + `scrollable-region-focusable`. Heredoc commit messages with `{ … '` are rejected: Write `tmp/<NNN>/msg.txt`, `--amend -F`.
- **(034) theme-contrast helpers:** the 029 block's `rule()` wants exactly one rule with that exact selector, so a new selector *list* (`a, b {}`) or a second rule for the same selector breaks it; the 034 block's `fills()` merges every rule whose comma-split list names the selector. Compute palette values lazily (`measured()` inside `it`), not at describe time (an `expect` at collection fails the whole suite). Design §5 values are browser-measured: a token computation can floor 0.01 lower (card border 4.05 vs 4.06): pin the computed value, list it as a deviation.
- **(036)** A `fills()` that merges every rule naming a selector also merges `@media (forced-colors)` rules (`background-color: Mark` wins): strip those blocks first (036 block in theme-contrast). A forced-colours override of a component with a variant rule (`.terminal .x`, 0,2,0) must name the variant selector too, or the variant colour wins and gets forced to Canvas. A synchronous `getComputedStyle` right after `focus()` returned a phantom `3px solid currentColor` outline: wait two rAFs.
- **(037)** jsdom has no `DragEvent`: drop = `new Event('drop')` + `Object.defineProperty(e, 'dataTransfer', { value })`; a `File`'s size via `defineProperty(file, 'size')`. Story `play` runs before story-shots captures (play-set statuses show in shots; measure waits 400 ms). Compiled selector lists use `,\n  ` but specs often write `, `: build regexes with `,\s*`. A static `href` on `lc-card` also stays on the host: anchor compat regexes at `a.card__link`. Stretched-link cards: 3 px corner probes on rounded `overflow: hidden` cards hit the card (clip), as for `clickable`. r1 review findings: (a) an outline on a non-focused ancestor (`:has(:focus-visible)`) computes to CanvasText in forced colours: add `@media (forced-colors: active) { outline-color: Highlight }`; (b) `::ng-deep` rules aimed at projected/child controls go in `:where(…)` so the control's own `position` etc. wins. `*/*` in JSDoc ends the comment: write `*\/*`. A measure that focuses/blurs can leave 1–5 px raster diffs: re-shoot without it before calling a diff.
- **(039)** Removing `role`/`tabindex` from an element with `(click)`/`(keydown)` and adding an empty `aria-labelledby` button trip angular-eslint `interactive-supports-focus` and `elements-content` (errors): house pattern is `<!-- eslint-disable-next-line <rule> -- <reason> -->` (18 templates). `code-block.region.spec` reads only the *first* `@media (forced-colors: active)` block: put new forced rules after the body's (file end). Log-viewer line hover and level tints are both `background-color` on the line and the tint (later, 0,2,0) wins: hover never composites over a tint (design 039 §5 assumed it: 3.23 vs real 3.49). `getComputedStyle(el, '::-webkit-slider-thumb')` returns the input's own style: prove thumb rings by spec + a held-focus shot. A 68-shot `--measure` run hung once at 0 % CPU (kill needs approval): rerun the rest as a separate run.
- **(040)** Jest loads no component styles: an element hidden only by CSS (`visibility: hidden` file input) is a visible, unlabelled control to axe in jsdom (`label` violation). Append `compile(resolve(__dirname, '<name>.component.scss')).css` as a `<style>` to `document.head` (remove in `afterAll`): jsdom computes `visibility`/`pointer-events` from it and axe honours it; `:host` rules don't break it.
- **(041)** `lc-accordion` body sets `line-height: 1.6` (22.39 px at 14 px): design sketches of content inside it assume 21 px lines (row heights, `lh`-based offsets differ; widths match). Design ASCII labels can differ from the prototype's real strings: take the strings whose measured values the §9 table quotes, note it.
- **(042)** Chrome counts an `<svg>`'s own *unscaled* box in its scroll container's scroll range (transform `scale()` doesn't shrink it): a sizer can't cut that; clip it in a wrapper (`display: contents` by default keeps rendering identical). `[style.--x]="'12px' | null"` works in Angular 22 and jsdom (`style.getPropertyValue`); jsdom stores `scrollLeft`. Adding `[attr.tabindex]` makes an `interactive-supports-focus` eslint-disable unused (new warning). Dart-sass expanded output separates top-level rules with a single `\n` (strip-and-hash specs). New story panels on tokens turn their raw dark text unreadable in dark (axe): move the inks too. New focus stories surface pre-existing axe issues: axe the unchanged counterpart story on the same build to prove it.
- **(043)** axe `target-size` measures the border box only: a `::before` hit area doesn't count, and a 20 px button nested in another target (select × inside the combobox) fails even with a 24 px pseudo area; a free-standing one passes by spacing. Positioned `::before` areas hit-test up to ~0.75 px wider than computed (layer snapping): out-probes at edge + 3.5 px. Wrapping a bare checkbox in an `inline-flex` label moved it 2 px; a plain inline label is hash-identical (test by injecting the rule in `--measure` + `--compare=<designer proto dir>`). Moving theme declarations into a mixin: `sed -n 'a,bp' file > tmp/<NNN>/piece` + `cat` pieces (passes; `cp`/`cd` into the scratchpad needs approval), then a temp spec compares the compiled root token maps old vs new (`zz-old-*.scss` beside the file). New `:not(.x-invalid)` in a hover rule breaks specs that count rules mentioning the class (`input.error-class.spec`).
- **(044)** A variant block nested after a state rule of equal weight overrides it (`.x.x--filled` after `.x.x--error`: filled error had no red border): put the state rule last *inside* the variant block, then it also beats the variant's `:focus`. Story `play` with `userEvent.keyboard(' ')` / `'{Enter}'` on a `focus()`ed button activates it before story-shots captures; check the result with `waitFor(() => expect(…))` from `storybook/test`.
- **Designer's cause hypotheses can be wrong:** measure first (009: bar overflow was the page's scroll, not item min-content); record the refutation as a deviation.

**Why:** none of these show in the code; each first looked like a kit regression.
**How to apply:** check before debugging a fixture, story or shot diff; add new traps here.
