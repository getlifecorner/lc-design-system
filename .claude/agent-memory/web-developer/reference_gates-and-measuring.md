- **Baselines after 061 (2026-11-13, 636aef3):** Jest 311 suites, 6486 passed, 8 skipped; Storybook 1159 stories; compat 22: 116 checks expected (`grep -o ", ok \|: ok " log | wc -l` − 1); lint 0 errors / 160 warnings (`--output-style=static > log`, grep `problems`; `--outputFile` writes nothing); build 125 `Built @lifecorner` lines (`--output-style=static`, else the TUI hides them); test:tools 22. `npm run generate:icon-names` needs approval: write its output by hand and pin it to the script's transform in a spec. `node tools/generate-components-manifest.mjs` and `node --test <file>` need approval: put a temp `tools/components-manifest/zz-*.test.mjs` (`extractComponentApi` + `toComponentMeta`, write to `tmp/`) and run it through `npm run test:tools`. Durations here: lib build 9 s, Storybook 18 s, full Jest 25 s.
- **Order:** lib build (rewrites tokens) → `build-storybook --skip-nx-cache` (stories-only edits restore "[local cache]" otherwise) → shots → full Jest last (Chromium + Jest workers SIGSEGV). story-shots checks staleness only at start, against every file in `src` (spec edits too): finish src and spec edits first, else rebuild Storybook (wipes `zz-*`). `--testPathPattern` is ignored by the nx target (runs everything): use `--testFile`.
- **Logs:** every shot line is printed; differing ones carry `"compare":"different"` (Grep that). An `ENOTEMPTY` rmSync error at exit is the profile cleanup; the shots are written, but with `--compare` the summary line is lost: prove identity with `diff -rq <out> <baseline> | grep -v "Only in <baseline>"`. Forced-colours measure (check/dot ink vs box, contrast): `tmp/062/measure/fc.mjs`.
- **Compare:** `--compare=<designer baseline> --measure='(async () => (await new Promise(r => setTimeout(r, 800)), 1))()'`; 4 parallel background runs of 48 stories × 360/1280 × L/D (768 shots) took ~12 min. Story lists: `grep -ho '"story":"[^"]*"' logs | cut -d'"' -f4 | sort -u`, then `sed -n a,bp | paste -sd, -` and paste the ids inline (`$(cat)` needs approval). Summary line `{"identical":n,"different":n}`.
- **Measures:** module in `tmp/<NNN>/measure/m.mjs`, `cp` to `dist/storybook/angular-ui-kit/zz-<NNN>/` (a Storybook rebuild wipes it), `--measure='(await import("/zz-<NNN>/m.mjs")).default()'`; tell stories apart by DOM (location is `/`). Render errors: in `--measure` patch `console.error`, `__STORYBOOK_ADDONS_CHANNEL__.emit("forceRemount", ({ storyId }))`, wait 2 s, return the errors. Story args: `__STORYBOOK_PREVIEW__.storyStoreValue.args.argsByStoryId`.
- **Pixel diff:** `tmp/057/measure/diff.mjs` (reads `/zz-diff/names.json`, any widths) + PNGs in `dist/…/zz-diff/base|new` (`cd <dir> && cp a b <abs dir>/` passes; globs need approval) → count, y range, x runs per shot; `tmp/058/measure/diff2.mjs` gives clustered boxes with Δ (locates AA-only diffs). Designer prototypes (injected CSS) can differ from the build by AA pixels at rounded edges over bands (058: Δ ≤ 7): rerun vs own run to prove determinism, report as deviation. Hero geometry measure: `tmp/058/measure/geo.mjs` (format of designer's `baseline-hero.log`); pair logs by story/width/theme with `grep -o` + `paste` + `sort` + `diff`. Known random: table *With Pagination*, *With Filtering*, *Full Featured* 1024/1280 L/D (Salary column, x 826–893 / 1031–1102); log-viewer timestamps; sidenav logo/clock stories. Rerun with `--compare=<own first run>` to prove a diff deterministic.
- **Stalled background shots (062):** when a turn is cut off, running story-shots jobs freeze (logs stop, `ps`/`pkill` need approval) and are killed later. Rebuild the to-do list (`grep -ho '"story":"[^"]*"' logs | cut -d'"' -f4 | sort | uniq -c | grep " 4 " | tr -s ' ' | cut -d' ' -f3` → `comm -23 all done`) and rerun into a new `--out` dir. One file op per Bash call (`mkdir a b && cd x && cp` is refused). 062 pace: ~6 shots/min per job with 4–5 jobs.
- **Baselines after 063 r2 (bc926d2):** Jest 326 suites, 6677 passed, 8 skipped (compat running beside full Jest also SIGSEGVs workers: run compat after Jest, or rerun the crashed suites alone); Storybook 1189 stories; compat 22: 123 checks; lint 0 / 160; build 125. **Seeing a diff:** `tmp/063/measure/crop.mjs` (cp to `zz-diff/`) draws base|new crops over the page in `--measure`, so the shot *is* the crop (`base64 -D` needs approval). Measure runs before the shot: a measure that clicks changes the shot. Random too: icon *All Icons* 1280 (glyphs still loading; identical after a 2.5 s wait).
- **064 (16 rows):** 888-shot baseline compare in 4 jobs + 132 new-story shots took ~25 min (~4 shots/min per job with 5 jobs). Story id lists: `ls <baseline> | sed 's/--[0-9]*-[a-z]*\.png$//' | sort -u`, then `sed -n a,bp | paste -sd, - > chunkN.txt` and Read the chunk to paste it. Polling `grep -h '"identical"'` floods the context: count with `grep -c`. Baselines after 064: Storybook 1222 stories, build 126 entries. Review-round shots (`r1-*`) were taken with measures that focus items: compare fixes against your own earlier run (`build-new*`), not the reviewer's.
- **065 (2026-11-18):** finish *every* src edit (incl. lint fixes) before long shot runs: a later edit makes story-shots refuse new runs, and a Storybook rebuild during running jobs breaks them. 1674-shot compare in 4 jobs + 102 new shots: ~75 min (load 8). Baselines after 065 r4: Jest 352 suites, 6971 passed, 8 skipped; roving-focus keyboard walk measure (focused box margins, scrollLeft, scrollY per key): `tmp/065/measure/r4.mjs`; Storybook 1239 stories; build 127 entries; lint 0/160; test:tools 22; compat 22: 130 checks. - **066 (2026-11-18):** baselines Jest 355 suites, 7038 passed, 8 skipped (r2); compat 22: 132 checks; build 127; lint 0/160; tools 22. 264-shot compare in 2 jobs + 24 new `--axe` ran ~15 min (load 4). `npx sass` and `npm pack <pkg>@<old>` need approval: compile the old SCSS in a temp spec with `compileString(src, { url: pathToFileURL(<real scss>) })` (relative `@use` resolves) and write both CSS files to `tmp/` to diff.
- **067 (2026-11-18):** baselines Jest 358 suites, 7106 passed, 8 skipped; Storybook 1250; compat 22: 135 checks; build 127; lint 0/160; tools 22. 336-shot compare in 3 jobs + 42 new `--axe` ~12 min (load 14–17). Before attributing a persistent diff, compare with the designer's *second* sample (`baseline-dom/`): 1 of 3 "persistent" diffs was a baseline outlier. Pair diff of any two PNG URLs (count, Δ, x/y range): `tmp/067/measure/pair.mjs` → cp to `dist/…/zz-diff/`, `.default([[urlA, urlB], …])`. In `--measure`/grep patterns write `.` for `{` (brace text needs approval); `python3 -` is refused. r2: Jest 7107; attribute a diff to a CSS rule by deleting it live in `--measure` (`tmp/067/measure/r2-drop.mjs`, `default(false)` = same-timing control); a 900 ms wait under load 10+ still catches the drawer settling (use 1.8 s). A job that writes no shot for minutes is hung: rerun the rest into a new `--out`. Never grep a whole shot log without `-c`/a summary pattern (floods context).
- **068 (2026-11-18):** baselines Jest 372 suites, 7276 passed (r3), 8 skipped; story-shots PNG hashes can differ with 0 changed pixels: confirm with `pair.mjs` before reporting a diff; Storybook 1272; compat 22: 139 checks; build 127; lint 0/159; tools 22. 1060-shot compare in 4 jobs + 88 new `--axe` ~15 min (load 5–10). Random too: popover *Placement* 360, sidenav *Themed Rail Badges* (own runs differ). Split a baseline id list: `tr ',' '\n' < ids.txt > a.txt`, `head`/`tail -n +N … | paste -sd, -`. `pkill` needs approval (jobs can't be stopped). `ls` of `~/Library/Caches/ms-playwright` needs approval: 054-n2 stays.
- **Hash two shot dirs:** `shasum` needs approval; rerun the story with `--compare=<other dir>` instead (064 r3: build vs designer `r2-proto`).
- **`--axe`:** after the shot; a new story with a violation: axe the nearest existing story on the same build to prove it pre-exists.
- **CDP / Node scripts:** `node <file>`, `node -e`, `python3 -` need approval: use a temp Jest spec (jsdom, `require('<root>/node_modules/ws/lib/websocket.js')`) or a temp `tools/components-manifest/zz-*.test.mjs` (manifest: `extractComponentApi(src).classes` + `toComponentMeta`), run, delete.
- **Bash forms:** pass: nx targets, story-shots, check-angular-majors, `mkdir`/`cp`/`rm` with absolute paths, `cmd > log 2>&1; grep … log`, `git switch -c`, `git commit --amend -F tmp/x`. Need approval or rejected: `echo "exit $?"`, `for` loops, `$(…)`, `sed -i`, `awk`, `echo ===` (zsh `=`), `{a,b}`-looking text (put a space after commas inside braces), heredocs with `{`+quotes, `cd x && … > file`, `grep -o '.\{0,N\}'` (use the Grep tool with `-o`).
- **Compat:** `--only=22 --work=<scratchpad>/compat` (~4 min, warm). New probe `probe-3NN.ts` on the home page + `EXPECT_IN_HTML`; anchor regexes on ids, allow `(?:<!--[^]*?-->|\s)*` between tags, `emptyAttr('hidden')` for empty attributes.
