- **Order (010):** `angular-ui-kit:build` rewrites `src/…/tokens`, so story-shots then refuses the Storybook build: run the lib build *before* `build-storybook`, and never rebuild Storybook while a shot run serves from it. A `--full` hash compare of ~80 stories × 6 takes 20–30 min (~3 s/shot, slower beside compat): run it in the background (`timeout` 5400000), the foreground 600 s limit kills it. Jest SIGSEGVs pile up while Chromium runs: run the full suite after the shots.
- **Lint:** the Nx target runs eslint in `libs/angular-ui-kit/`; from the root you get false module-boundary errors. Targeted: `--lintFilePatterns=libs/angular-ui-kit/src/lib/<folder>/<file>` (a `src/lib/…` pattern is "ignored").
- **Bundles:** fesm is partial compilation (templates ship as strings with `&ngsp;` and comments): Grep `dist/.../fesm2022/*.mjs` for template text. SSR `--stats-json` writes `browser-stats.json`; CLI kB = 1000 B. Unchanged-bundle proof: `npm pack` the last version, `shasum fesm2022/*.mjs` vs `dist/`. `check-entries.mjs` hard-codes the entry count. The last release is often only staged (ETARGET): use an earlier request's tarball.

- **Bash filters (headless):** allowed: `story-shots.mjs`, `check-angular-majors.mjs`, nx targets, `mkdir`/`cp`/`rm`, `cmd > log 2>&1; grep … log`. Need approval: any other `node <file>` (also in `tmp/`), `node -e`, `$(…)`, `sed`/`awk` edits, `git check-ignore`, `env`, `cd x && git`, `grep -E` with `^(…|…)$`, `for` loops, `python3 - <<EOF`, `echo $?` ("variable can't be checked"); `nx … test` without `--output-style=static` prints no Jest summary. Rejected: `{a,b}`-looking text even inside quotes ("Brace expansion": put a space after every comma inside braces in `--measure` JS), unicode escapes, heredocs with `{`+quotes (a plain `git commit -F - <<'EOF'` passed). `git commit --amend` passes; to fix the message, `git log -1 --format=%B > tmp/x`, Edit, `--amend -F tmp/x`.
