- **Baselines after request 017 (2026-10-25):** Jest 181 suites, 4351 passed, 8 skipped; Storybook 908 stories; compat 22: 71 checks; 300-shot `--full` compare ~20 min in the background (compat ran beside it fine). (015: Jest 177 suites, 4282 passed, 8 skipped (8 `*.axe.spec.ts` on axe-core 4.14, full suite ~11 s); lint 0 errors, 162 warnings; compat 22: 63 HTML checks; Trusted Types check 194; build ~10 s (119 entries + primary = 120 "Built"); Storybook ~17 s, 899 stories; compat `--only=22` ~3 min. Whole-Storybook axe sweep: the designer's one-measure sweep (their review-techniques memory) plus a baseline diff (copy the baseline logs into `dist/storybook/…/zz-axe/`, `fetch` them, `rm -r` after); four width/theme runs in parallel took ~6–8 min; affected-story `--axe` runs fit the 600 s foreground limit and keep the turn alive meanwhile. Jest prints counts only with `--output-style=static --skip-nx-cache`; a worker SIGSEGV happens now and then: rerun. `--testFile=<name or regex>` works, `--testPathPattern` is ignored.
- **Order (010):** `angular-ui-kit:build` rewrites `src/…/tokens`, so story-shots then refuses the Storybook build: run the lib build *before* `build-storybook`, and never rebuild Storybook while a shot run serves from it. A `--full` hash compare of ~80 stories × 6 takes 20–30 min (~3 s/shot, slower beside compat): run it in the background (`timeout` 5400000), the foreground 600 s limit kills it. Jest SIGSEGVs pile up while Chromium runs: run the full suite after the shots.
- **Lint:** the Nx target runs eslint in `libs/angular-ui-kit/`; from the root you get false module-boundary errors.
- **Bundles:** SSR `--stats-json` writes `browser-stats.json`; CLI kB = 1000 B. Unchanged-bundle proof: `npm pack` the last version, `shasum fesm2022/*.mjs` vs `dist/`. `check-entries.mjs` hard-codes the entry count. The last release is often only staged (ETARGET): use an earlier request's tarball.
- **story-shots:** refuses a build older than `src` (spec edits count). Designer baselines may be `--full` (011: only the stories taller than 900 px differ in a non-full compare): re-shoot just the differing stories with `--full` before diffing pixels (`file *.png` needs approval). A text Range over a clipped sr-only span reports the unclipped width: skip `.…sr-only` when measuring overflow. `--measure` runs before the shot, so it can inject a `<style>` to try CSS against `--compare` without rebuilding. Story args: `updateStoryArgs` via `__STORYBOOK_ADDONS_CHANNEL__` did not re-render in 009; flip the DOM attribute the story's style keys on instead. Root font size (016): an injected `<style>html{font-size:200% !important}</style>` works, but the first boxes read stale (100 %) layout: do a settling pass (focus each target, two rAFs) before measuring. After `el.focus()` wait two rAFs. Flaky hashes: sidenav logo stories, chat message-status, `components-chat--user-avatar` (clock times relative to `now`). `--axe` runs axe-core from `node_modules` after the shot; an older build can be probed with a CDN `<script>` in `--measure`.
- **Pixel diff without deps:** `mkdir dist/storybook/angular-ui-kit/zz-diff`, `cp` baseline + new PNGs there, load both in `--measure` (`new Image()`, canvas `getImageData`), return differing rows; `rm -r` the dir after. `cp -R` and `cp` with globs need approval: `cd <shot dir> && cp a.png b.png … ../../…/zz-diff/base/` passes. "Content moved up N px" diffs: `tmp/017/measure/shift.mjs` (rows equal to the baseline N px lower count as explained). Designer expected-diff lists can miss stories that show an error at load (email-input Team Invite).
- **Measure modules (016):** keep them in `tmp/<NNN>/measure/*.mjs`, `cp` into `dist/storybook/angular-ui-kit/zz-<NNN>/`, run `--measure='(await import("/zz-<NNN>/x.mjs")).default()'` (no quoting/brace filters); any Storybook rebuild wipes `zz-*`. Contrast: composite translucent fills (lc-alert's bg is rgba; the first non-transparent layer alone gave 1.35 instead of 4.78): reuse `backdrop()` from `tmp/016/measure/link.mjs`. Prerender determinism: `cd <work>/app-22 && npx ng build` (passes) then `cmp` the page. Temp extractor checks: `npm run test:tools -- tmp/<NNN>/x.test.mjs`.
- **Prerendered pages in the browser:** copy compat `browser/` files into `dist/storybook/angular-ui-kit/c8/` (explicit `cp a b dir/`), fix `<base href>` with Edit; sandboxed iframe = no JS; hydration done = `[jsaction]` count 0; iframe `src="/c8/"` (dir → index.html) with base `/c8/`, an inline `console.error` capture script after `<base>` (016).
- **Bash filters (012 additions):** `git checkout -b` needs approval, `git switch -c` passes. `node tools/generate-components-manifest.mjs` needs approval (writes into the Storybook dist); `test:tools` covers the extraction. macOS `grep -o '.\{0,400\}'` fails (max repetition 255). (013) `node scripts/generate-character-assets.mjs` and `shasum` need approval: apply the same `d` edits to the dark file and both data strings by hand (the assets spec proves rule/strings), and pin old files by git blob id (`git rev-parse v3.11.2:<path>` passes; in Jest `sha1('blob <bytes>\0' + text)`).
- **(014) `npm install` of any package needs approval** (not in settings.json): a new devDependency blocks headless runs → hand off `needs-owner` after doing everything else; a spec can be probed against another checkout's copy by absolute import in a temporary spec.
- **Bash filters (017):** `grep -o` with `\|` alternation and `grep -v "^\s*$"` need approval: use the Grep tool (`-o`, `output_mode: content`) on the log instead.
- **Bash filters (010 additions):** `echo $?`, `git fetch`, `git -C …` need approval; a heredoc/append with `{` + quotes is rejected: append story code with Edit.
- **Bash filters (headless):** allowed: `story-shots.mjs`, `check-angular-majors.mjs`, nx targets, `mkdir`/`cp`/`rm`, `cmd > log 2>&1; grep … log`. Need approval: any other `node <file>` (also in `tmp/`), `node -e`, `$(…)`, `sed`/`awk` edits, `git check-ignore`, `env`, `cd x && git`, `grep -E` with `^(…|…)$`, `for` loops. Rejected: `{a,b}`-looking text even inside quotes ("Brace expansion": put a space after every comma inside braces in `--measure` JS), unicode escapes, heredocs with `{`+quotes (a plain `git commit -F - <<'EOF'` passed). `git commit --amend` passes; to fix the message, `git log -1 --format=%B > tmp/x`, Edit, `--amend -F tmp/x`.
