- **Baselines after 073 (2026-11-24):** Jest 396 suites, 7618 passed, 8 skipped; lint 0 errors / 159 warnings; build 127 `Built @lifecorner` lines; compat 22: `grep -o ", ok \|: ok " log | wc -l` − 1 = 144; test:tools 22. Full Jest with `--maxWorkers=4`; a SIGSEGV "worker terminated" suite (a different one each run) passes alone. `--testPathPattern` is ignored by the nx target (runs everything): use `--testFile`.
- **Order:** finish every src/spec/story edit → lib build → `build-storybook --skip-nx-cache` (grep `Failed to build the preview`) → shots → commit → full Jest → compat (`--only=22 --work=<scratchpad>/compat`, ~4 min; never beside Jest). story-shots refuses a build older than any `src` file.
- **Compare:** `--compare=<designer baseline> --measure='(async () => (await new Promise(r => setTimeout(r, 800)), 1))()'`, 3 jobs of ~16 ids × 3 widths × L/D ≈ 8 min. Summary line: grep `'^{"identical"'` (never `-h '"identical"'`). Play-function stories (select *Focus After Tap*, *Grouped Options, Search (DE)*) differ under a measure wait: rerun without `--measure` vs the baseline. Known random: table *Full Featured*/*With Filtering*/*With Pagination* 1280, sidenav *Themed Rail Badges*/*Action Items*, area-map *All Bands*, log-viewer timestamps, icon *All Icons*, popover *Placement* 360. PNG hashes can differ with 0 changed pixels: `tmp/067/measure/pair.mjs`.
- **Measures:** module in `tmp/<NNN>/measure/m.mjs` → `mkdir` + `cp` to `dist/storybook/angular-ui-kit/zz-<NNN>/` (a rebuild wipes it) → `--measure='(await import("/zz-<NNN>/m.mjs")).default()'`; tell stories apart by DOM. Read logs with `jq -c 'select(.story==…) | [...]'` (passes). Generic geometry module (stat-trend header/badge/glyph gaps, combobox frame end, select/number-input label gaps): `tmp/073/measure/m.mjs`. Crops/pixel diff: `tmp/063/measure/crop.mjs`, `tmp/057/measure/diff.mjs`, `tmp/058/measure/diff2.mjs`. Live rule drop: `tmp/067/measure/r2-drop.mjs`. Trace in browser: push to `globalThis.__x`, rebuild (`tmp/069/measure/trace.mjs`).
- **Overlay/menus:** `--full` fires a scroll and closes kit-handled anchored menus: shoot those without `--full`. A job that writes no shot for minutes is hung (can't be killed): rerun the rest into a new `--out`.
- **`--axe`** runs after the shot and includes the experimental `label-content-name-mismatch`; a new story with a violation: axe the nearest existing story to prove it pre-exists.
- **No approval needed for:** nx targets, story-shots, check-angular-majors, `mkdir`/`cp`/`rm`/`mv` with absolute paths, `cmd > log 2>&1; grep … log`, `git switch -c`, `git add <files> && git commit -F tmp/x`, `jq`. **Refused or approval:** `node <file>`, `node -e`, `python3 -`, `npx sass`, `shasum`, `pkill`, `for` loops, `$(…)`, `sed -i`, `awk`, `cd <dir> && grep …` chains with pipes to `head`, `grep --include=*.ts` (zsh glob), `git -C`, `npm run generate:icon-names`. Instead: temp Jest spec (`compile` from sass, `encapsulateStyle` from `@angular/compiler`, `ws` for CDP) or a temp `tools/components-manifest/zz-*.test.mjs` via `npm run test:tools`.
- **Session limits:** a session rooted outside the repo gets `git`/`mkdir`/redirects refused: do the work, write `tmp/<NNN>/msg.txt`, hand to owner. Node v23 broke compat prerender (v24 works). No Playwright/WebKit runnable: 054-n2 (Safari) stays in BACKLOG; Chromium `HTMLElement.click()` without focus stands in for a tap.
