# Kit requests from proving the Finance Intelligence app shell (2026-10-30)

- **From:** finance-intelligence (IT finance controlling, Angular 22, `@lifecorner/angular-ui-kit` 3.14.0)
- **Approved concept:** [docs/ux/concepts/app-shell.md](../concepts/app-shell.md), sections 5.4, 7 and 8 (German)
- **Found by:** the UX review of spec 001, comparing the built shell at 360 and 1280 px with the approved design
- **Status:** open

| #   | Component                | Gap                                                                                                                                                                                                                                           | Proposal                                                                                                                                      | Accepted when                                                                                                                                      | Our transition until the release                                     |
| --- | ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 1   | `lc-app-page`            | The horizontal page padding is 24 px on the phone and 56 px on the desktop. The design uses 16 and 32 px, so the page `h1` lines up with the product name in `lc-header`. `--lc-app-page-padding-x` exists in the code but is not documented. | Document `--lc-app-page-padding-x` (per breakpoint) as a public theming variable, or add an input such as `paddingX: 'default' \| 'aligned'`. | A consuming app can set 16 px below 640 px and 32 px from 1024 px with a documented hook; the `h1` aligns with the header title; there is a story. | Kit default 24/56 px.                                                |
| 2   | `lc-page-header`         | There is no input for the space above the header. Inside `lc-app-page` the `h1` sits 64 px below `lc-header` on the phone and about 100 px on the desktop; the design places it directly below the header (8–16 px).                          | An input or documented variable for the top spacing, for example `spacingTop: 'none' \| 'sm' \| 'md'` (default unchanged).                    | The `h1` can start 8–16 px below a transparent `lc-header` without overrides; the skeleton variant follows the same spacing.                       | Kit default spacing.                                                 |
| 3   | `lc-empty-state`         | The icon renders bare. The design shows it in a tinted circle: 48 px, `--color-primary-100`, icon in `--color-primary-700`.                                                                                                                   | An input such as `iconTone: 'neutral' \| 'primary'` that renders the icon in a tinted circle.                                                 | The tinted circle comes from tokens, the icon stays `aria-hidden`, and there is a story for a state page with an action.                           | Icon without a circle.                                               |
| 4   | `lc-empty-state`         | The message stays at 14 px, smaller than in the design, and there is little space before the action. `size="lg"` only adds space above the icon.                                                                                              | Let `size` (or a new input) also scale the message and the space before the projected action.                                                 | A state page with an action matches the design at 360 px without overrides; there is a story.                                                      | Kit default.                                                         |
| 5   | `lc-avatar`              | Used as the user-menu trigger without a name, it shows a "?" on petrol. The design shows a neutral grey round avatar with a person icon.                                                                                                      | A neutral fallback for a missing name, for example `fallback="person"`.                                                                       | Without a name the avatar renders a person icon on a neutral token background, with an accessible label; there is a story.                         | The kit's icon trigger while `/me` returns no name.                  |
| 6   | `lc-button`              | `variant="outline"` renders dark text; the design shows the outline action with text in the primary colour.                                                                                                                                   | A primary tone for the outline variant, for example `tone="primary"`.                                                                         | Outline text and border come from primary tokens and meet WCAG 2.2 AA contrast; there is a story.                                                  | `outline` with dark text.                                            |
| 7   | `lc-sidenav-placeholder` | The docs say to set the `--lc-sidenav-*` variables on an ancestor, but the `dark` theme declares them on the element itself (`:host`), so inherited values lose. The placeholder renders near-black instead of the app's rail colour.         | Either fix the docs (set the variables on the element) or let the theme respect inherited values.                                             | A rail colour set on an ancestor shows in both `lc-sidenav` and `lc-sidenav-placeholder` with `theme="dark"`; the docs match.                      | Variables set directly on `lc-sidenav` and `lc-sidenav-placeholder`. |
